Simulado Interativo: JavaScript

1. Estrutura de Repetição DO WHILE

1. No exemplo de solicitar números até digitar zero, qual condição mantém a repetição ativa?
  • A. numero === 0
  • B. numero !== 0
  • C. numero > 100
  • D. numero < 0
  • E. numero == undefined
Alternativa B. A repetição deve continuar ativa enquanto o número digitado for diferente de zero.
2. Qual é a principal característica do do while?
  • A. Ele nunca executa o bloco de código
  • B. Ele executa o bloco apenas se a condição for falsa
  • C. Ele substitui o uso de variáveis
  • D. Ele só pode ser usado com números
  • E. Ele executa o bloco pelo menos uma vez antes de testar a condição
Alternativa E. Ao contrário do while convencional, o do while executa os comandos uma primeira vez para só depois testar a condição lógica.

2. Introdução a Funções

1. Para que serve o return em uma função?
  • A. Para exibir automaticamente uma mensagem no console
  • B. Para acessar arquivos externos
  • C. Para retornar um valor produzido pela função
  • D. Para criar uma variável dentro da função
  • E. Para solicitar dados ao usuário
Alternativa C. O return devolve um dado processado internamente para a linha externa onde a função foi chamada.
2. O que são parâmetros em uma função?
  • A. Valores retornados obrigatoriamente pela função
  • B. Informações que a função declara que precisa receber para executar sua tarefa
  • C. Mensagens exibidas automaticamente no console
  • D. Comandos usados para encerrar uma repetição
  • E. Tipos de dados usados apenas em variáveis globais
Alternativa B. Parâmetros funcionam como placeholders ou variáveis internas prontas para aceitar os argumentos passados no momento da execução.

3. Arrays

1. Qual método remove o primeiro elemento de um array?
  • A. pop
  • B. push
  • C. shift
  • D. unshift
  • E. concat
Alternativa C. O método shift() remove a primeira posição (índice 0) e rearranja o array, enquanto o pop() remove o último elemento.

4. Introdução ao Assincronismo

1. Quais são os três estados principais de uma Promise?
  • A. start, middle e end
  • B. true, false e null
  • C. pending, fulfilled e rejected
  • D. sync, async e await
  • E. then, catch e finally
Alternativa C. Uma Promise inicia em estado pendente (pending) e pode terminar resolvida com sucesso (fulfilled) ou rejeitada com erro (rejected).

5. Projeto de Estoque CRUD

1. Para que serve o método find no projeto?
  • A. Para remover todos os produtos do array
  • B. Para procurar um produto pelo código dentro do array
  • C. Para ordenar os produtos pelo nome
  • D. Para converter o array em string
  • E. Para adicionar um novo produto ao estoque
Alternativa B. O método find() percorre o array e retorna o primeiro objeto que atenda ao critério de busca fornecido.
