📚 Como funciona o localStorage?

O localStorage permite armazenar informações diretamente no navegador do usuário. Os dados permanecem salvos mesmo após fechar a página.

1. Salvar dados

localStorage.setItem("nome", "João");

2. Recuperar dados

let nome = localStorage.getItem("nome");

3. Remover um dado

localStorage.removeItem("nome");

4. Apagar todos os dados

localStorage.clear();
