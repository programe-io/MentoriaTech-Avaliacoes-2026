Explicação de cada parte HTML – Estrutura da página : informa que estamos usando HTML5. : inicia o documento. : contém configurações da página. : define o nome que aparece na aba do navegador. <body>: contém tudo que aparece na tela. CSS – Aparência do site O CSS serve para personalizar a página. background-color: muda a cor de fundo. color: muda a cor do texto. font-size: altera o tamanho da fonte. padding: cria espaço interno. border-radius: arredonda as bordas. text-align: alinha o texto. JavaScript – Interatividade O JavaScript permite que o site execute ações. Por exemplo: javascript function mostrarMensagem() { alert("Olá, mundo!"); } Essa função mostra uma mensagem quando o usuário clica no botão.
