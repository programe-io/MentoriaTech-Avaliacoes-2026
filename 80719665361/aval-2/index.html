Introdução à Web e à Internet

Conheça a história, os conceitos e o funcionamento das tecnologias que conectam o mundo.

Aluno: Gustavo

1. Introdução

A internet e a web estão presentes em nosso cotidiano. Utilizamos essas tecnologias para acessar sites, assistir vídeos, utilizar redes sociais e trocar informações.

Este trabalho apresenta os conceitos fundamentais sobre a internet, sua história, infraestrutura e o funcionamento da World Wide Web.

2. O que é a Internet?

A internet é um sistema global de redes de computadores interligadas que permite a comunicação e a troca de informações entre bilhões de dispositivos.

Principais características:

  • É uma rede mundial de redes.
  • Conecta bilhões de dispositivos.
  • Utiliza protocolos de comunicação.
  • Permite o compartilhamento de informações.

3. História da Internet

A internet surgiu na década de 1960, durante a Guerra Fria. Um dos primeiros projetos foi a ARPANET, desenvolvido pelo Departamento de Defesa dos Estados Unidos.

Década de 1960

Criação da ARPANET.

Década de 1970

Desenvolvimento dos protocolos TCP/IP.

Década de 1980

Expansão da rede para universidades.

Década de 1990

Popularização da internet comercial.

4. Infraestrutura da Internet

Apesar de parecer virtual, a internet depende de uma grande estrutura física para funcionar.

  • Data centers.
  • Servidores.
  • Cabos de fibra óptica.
  • Roteadores.
  • Satélites.
  • Equipamentos de rede.

5. Cabos Submarinos de Internet

Os cabos submarinos de fibra óptica conectam continentes e transportam grandes quantidades de informações entre diferentes países.

  • Percorrem milhares de quilômetros.
  • Utilizam tecnologia de fibra óptica.
  • Possuem alta capacidade de transmissão.
  • São fundamentais para a comunicação global.

6. O que é a Web (World Wide Web)?

A World Wide Web, conhecida como Web, é um sistema de documentos e páginas interligados por meio de hiperlinks e acessados através da internet.

Esses documentos podem conter textos, imagens, vídeos, sons e animações.

7. Como funciona a Web?

A Web utiliza o modelo cliente-servidor. O navegador solicita informações e o servidor responde enviando os dados solicitados.

1. Navegador envia uma requisição.
2. Servidor recebe a solicitação.
3. Servidor envia os dados.
4. Navegador exibe o conteúdo.

8. O papel de Tim Berners-Lee

Tim Berners-Lee foi o criador da World Wide Web. Ele desenvolveu essa tecnologia no final da década de 1980, enquanto trabalhava no CERN.

Três tecnologias fundamentais:

  • HTML: linguagem de marcação de páginas.
  • HTTP: protocolo de comunicação da Web.
  • URL: endereço de recursos na Web.

9. Internet x Web

Internet

É a infraestrutura global que conecta computadores e dispositivos.

Web

É um serviço que utiliza a internet para disponibilizar páginas e documentos.

Internet = Infraestrutura | Web = Páginas e documentos.

10. Conclusão

A internet é uma das tecnologias mais importantes do mundo moderno. Ela permite a comunicação global, o compartilhamento de informações e o acesso a diversos serviços digitais.

A Web utiliza essa infraestrutura para conectar páginas e documentos, facilitando o acesso ao conhecimento e à informação.
