Aumente sua produtividade com estes comandos fundamentais:

  • Alt + Z: Ativa a quebra de linha automática (Word Wrap).
  • Ctrl + B: Abre ou fecha o menu lateral de arquivos.
  • Ctrl + P: Pesquisa e abre arquivos rapidamente pelo nome.
  • Ctrl + Shift + K: Apaga a linha atual de código instantaneamente.
  • Ctrl + /: Comenta ou retira o comentário de uma linha ou bloco.
