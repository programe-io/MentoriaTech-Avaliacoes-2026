Conhecendo o HTML

O HTML (HyperText Markup Language) é a linguagem de marcação utilizada para estruturar as páginas que você vê na internet.

Principais Elementos

  • <h1>: Usado para títulos principais.
  • <p>: Usado para blocos de texto (parágrafos).
  • <a>: Usado para criar links.
  • <ul> e <li>: Usados para criar listas.

Para saber mais, acesse a documentação oficial na MDN Web Docs.
