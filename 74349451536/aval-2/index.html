Construindo um Gerenciador de Tarefas em JavaScript

Por Francisco Coelho • 11 de Agosto de 2026

Neste projeto prático[cite: 17], exploraremos os Fundamentos Lógicos com JavaScript através da criação de um algoritmo de simulação para um sistema de gerenciamento de tarefas[cite: 17].

O que o sistema deve permitir?

Para criar um gerenciador eficiente, nosso algoritmo precisará implementar as seguintes funcionalidades principais:

  • Cadastrar uma nova tarefa;
  • Listar todas as tarefas cadastradas;
  • Marcar uma tarefa específica como concluída;
  • Alterar a prioridade de uma tarefa já criada.

Regras de Validação:

  • O título da tarefa deve conter no mínimo 5 caracteres.
  • A prioridade deve ser definida por um valor numérico entre 1 (alta) e 3 (baixa).

Estrutura das Tarefas

Cada tarefa no sistema possui as seguintes informações essenciais:

  • código: Identificador único da tarefa;
  • título: Descrição resumida do que precisa ser feito;
  • prioridade: Nível de urgência (1 a 3);
  • concluida: Status que indica se já foi executada ou não.
