1. Tipos de Dados em JavaScript

Postado em Fundamentos

O JavaScript possui diversos tipos de dados essenciais para representar informações:

  • String: Textos delimitados por aspas simples, duplas ou crases (template literals).
  • Number: Trata números inteiros e decimais (ponto flutuante) da mesma forma (ex: 10 e 10.5).
  • Boolean: Representa valores lógicos: true ou false.
  • Undefined: Variável declarada, mas sem valor atribuído.
  • Null: Ausência intencional de valor.
  • NaN: Not a Number, valor especial do tipo Number para operações inválidas.

2. Declaração de Variáveis: var, let e const

Postado em Boas Práticas

Entenda a diferença no escopo e mutabilidade:

  • var: Forma antiga, com escopo abrangente e içamento (hoje menos recomendada).
  • let: Recomendado para valores que mudam durante a execução (escopo de bloco).
  • const: Para valores constantes que não sofrem reatribuição.

3. Operadores Aritméticos, Relacionais e Lógicos

Postado em Lógica de Programação

Os operadores nos ajudam a executar cálculos, realizar comparações e validar condições:

  • Aritméticos: Adição (+), Subtração (-), Multiplicação (*), Divisão (/), Resto (%) e Exponenciação (**).
  • Relacionais: Diferença entre igualdade simples (==) e estrita (=== - valida valor e tipo).
  • Lógicos: E (&&), OU (||) e NÃO (!).

4. Estruturas de Controle de Fluxo

Postado em Controle de Fluxo

Utilize if / else if / else para condições lógicas abrangentes e switch / case para verificação direta de valores exatos (lembre-se do uso do break e default).

Dica Rápida

Sempre prefira usar const por padrão, e mude para let apenas quando tiver certeza de que a variável precisará ser alterada no futuro.
