Aqui está um jogo completo no estilo "Subway Surfers" usando apenas **HTML, CSS e JavaScript (Canvas)**. O jogador controla um cubo que corre automaticamente. O objetivo é desviar dos obstáculos (vermelhos) e coletar as moedas (amarelas) mudando de pista. ### Como Jogar: * **Seta para a Esquerda ($\leftarrow$) ou A:** Move para a pista da esquerda. * **Seta para a Direita ($\rightarrow$) ou D:** Move para a pista da direita. --- ### Código Completo (Copie e cole em um arquivo `.html`) ```html Mini Subway Surfers

Coin Runner

Moedas: 0
Pontos: 0

Game Over!

Pontuação total: 0

Use as setas ← → ou A D para desviar.

``` ### O que este código faz: 1. **Mecânica de 3 Pistas:** O cenário é dividido em 3 colunas (pistas). O jogador muda de pista instantaneamente no comando, mas o visual do cubo desliza suavemente até o destino (efeito de interpolação). 2. **Geração Dinâmica:** O JavaScript decide aleatoriamente se vai criar um obstáculo ou uma moeda em uma das três pistas de tempos em tempos. 3. **Dificuldade Progressiva:** Quanto mais tempo você sobrevive, mais rápido (`gameSpeed`) os objetos caem, imitando a aceleração do Subway Surfers original. 4. **Sistema de Pontuação:** Correr aumenta seus pontos aos poucos, mas coletar moedas amarelas dá um bônus enorme de 500 pontos por moeda.
