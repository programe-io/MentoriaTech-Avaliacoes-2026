O que é HTML?

HTML (HyperText Markup Language) é a linguagem de marcação utilizada para estruturar páginas da web.

Com HTML podemos criar títulos, parágrafos, listas, imagens, links e diversos outros elementos que compõem um site.

Principais recursos do HTML

  • Estruturação de páginas web.
  • Criação de links.
  • Inserção de imagens.
  • Formulários para interação.
  • Organização semântica do conteúdo.

Curiosidades

  • Criado por Tim Berners-Lee.
  • HTML5 é a versão atual mais utilizada.
  • Funciona em conjunto com CSS e JavaScript.
  • É a base de praticamente todos os sites.
