Conhecendo o Índice de Massa Corporal

Neste mini blog vamos conhecer um pouco sobre o Índice de Massa Corporal, também conhecido como IMC, e entender como funciona um projeto de cadastro de pessoas para calcular e apresentar esse índice.

O conteúdo foi desenvolvido com HTML e CSS, utilizando conceitos estudados nas aulas de Desenvolvimento de Sistemas.

Este blog é informativo. Ele não realiza cálculos nem cadastros, pois foi desenvolvido exclusivamente com HTML e CSS.

O que é IMC?

O Índice de Massa Corporal (IMC) é um cálculo que relaciona o peso e a altura de uma pessoa. Ele é utilizado como uma referência geral para avaliar a relação entre essas medidas.

Como calcular o IMC?

IMC = Peso ÷ (Altura × Altura)

Para realizar o cálculo, utilizamos o peso em quilogramas e a altura em metros.

Exemplo

Peso: 65 kg

Altura: 1,70 m

Cálculo: 65 ÷ (1,70 × 1,70)

Resultado aproximado: 22,5

Classificação do IMC

O resultado do cálculo pode ser associado a diferentes faixas de classificação, conforme a tabela de referência utilizada no projeto estudado.

Abaixo do peso

IMC menor que 18,5

Peso normal

IMC de 18,5 a menos de 25

Sobrepeso

IMC de 25 a menos de 30

Obesidade grau I

IMC de 30 a menos de 35

Obesidade grau II

IMC de 35 a menos de 40

Obesidade grau III

IMC igual ou superior a 40

As classificações são apresentadas como referência didática e não substituem uma avaliação profissional de saúde.

Conhecendo o projeto de ficha de anamnese

Nas aulas, foi desenvolvido um projeto de controle de IMC. O sistema tem como objetivo receber informações de uma pessoa, calcular o IMC e apresentar os dados em uma tabela.

Informações utilizadas no cadastro

  • Nome da pessoa
  • Idade
  • Altura
  • Peso

Como os dados são organizados?

Após o cadastro, os dados são organizados em uma tabela, contendo o nome, idade, altura, peso, IMC e a classificação.

Nome Idade Altura Peso IMC Classificação
mizerá 25 1,97 m 90 kg 22,0 Peso normal
rodolfo 30 1,70 m 65 kg 22,5 Peso normal

Os dados apresentados na tabela são fictícios e servem apenas para demonstrar a organização das informações.

O que aprendemos no projeto?

HTML

Utilizamos o HTML para estruturar páginas, criar títulos, parágrafos, listas, tabelas e organizar o conteúdo.

CSS

Utilizamos o CSS para definir cores, fontes, espaçamentos, bordas e organizar os elementos visualmente.

Formulários

Aprendemos como os formulários recebem informações digitadas pelos usuários.

Tabelas

Aprendemos a organizar informações em linhas e colunas para facilitar a visualização.

Validação

Conhecemos a importância de verificar se os dados informados estão corretos.

Armazenamento

Conhecemos o localStorage, que permite armazenar informações no navegador por meio do JavaScript.

Conclusão

O projeto de controle de IMC nos ajuda a compreender como diferentes elementos de uma página web podem ser organizados para construir um sistema.

Com HTML e CSS, podemos criar páginas organizadas, bonitas e responsivas. A partir desses conhecimentos, podemos avançar para o JavaScript e desenvolver funcionalidades que tornam os sistemas interativos.
