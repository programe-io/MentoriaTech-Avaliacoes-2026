Fundamentos Lógicos com JavaScript — O Guia Definitivo de Revisão

Por [Isabela] | Categoria: Desenvolvimento Web & Lógica

Olá, devs! Sejam bem-vindos ao nosso espaço. Hoje, vamos fazer aquela revisão de ouro sobre os Fundamentos Lógicos com JavaScript. Se você está começando na programação ou precisa relembrar os conceitos antes de partir para um projeto mais complexo, este post é para você.

Prepare o café e vamos revisar desde os tipos de dados até as estruturas condicionais. ☕️💻

🧱 1. Os Tipos de Dados (A Base de Tudo)

O JavaScript trabalha com diferentes tipos de dados para representar as informações. Confira os principais:

  • String: Textos. Podem ser escritos com aspas simples, duplas ou crases. (Dica: A crase permite a interpolação!)
  • Number: O JavaScript usa o mesmo tipo para números inteiros (10) e decimais (10.5).
  • Boolean: O clássico true ou false.
  • Undefined: Quando uma variável é criada, mas ainda não recebeu valor.
  • Null: Representa a ausência intencional de valor.
  • NaN (Not a Number): Um valor especial que ocorre quando uma operação matemática falha.

Dica: Use o typeof no console para verificar o tipo de qualquer variável! 🕵️‍♂️

📦 2. Declarando Variáveis: var, let e const

  • var: A forma mais antiga. Hoje é menos recomendada.
  • let: A forma moderna recomendada para variáveis que podem mudar de valor.
  • const: A constante. O valor não pode ser alterado depois de definido.

⚙️ 3. Operadores: A Matemática e a Lógica

Dividimos os operadores em três grupos principais:

  1. Aritméticos: +, -, *, /, %, **, ++/--. (Atenção à precedência! Parênteses mudam tudo).
  2. Relacionais: >, <, >=, <=, == e ===. (A boa prática é sempre preferir o estrito ===).
  3. Lógicos: && (E), || (OU) e ! (NÃO).

🔀 4. Estruturas de Seleção (Condicionais)

  • if / else if / else: Verifica condições lógicas. O else é o plano B.
  • switch / case: Ideal para comparações de valor exato. O break é essencial! O default é o "plano B" executado quando nenhum case dá match.

🔁 5. Estruturas de Repetição (Loops)

  • for: Quando sabemos a quantidade exata de repetições.
  • while: Repete enquanto a condição for verdadeira (testa no início).
  • do while: Executa o bloco pelo menos uma vez antes de testar a condição.

📚 6. Funções e Arrays (Introdução)

Funções: Podem ser declaradas de várias formas, como Arrow Functions (que são mais curtas e elegantes).

Arrays: Listas ordenadas com indexação zero (o primeiro item é o índice 0). São dinâmicos e heterogêneos.

🎯 Conclusão

A revisão dos fundamentos é o que garante que você não trave na hora de construir a lógica de um sistema. Pegue esses conceitos e comece a praticar em pequenos algoritmos no seu console!
