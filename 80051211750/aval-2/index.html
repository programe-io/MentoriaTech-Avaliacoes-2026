#INTERNET

O QUE É A INTERNET DE VERDADE?

Muita gente usa todo dia sem perceber, mas a Internet é um sistema global de redes de computadores interligadas usando protocolos padronizados (como o TCP/IP).

Ela conecta bilhões de celulares, PCs e servidores para rodar e-mail, streaming, jogos e nuvem!

@ned.code: Sem protocolos padrão cada computador falaria uma língua diferente!

#CABOS

A INTERNET NÃO MORA NAS NUVENS!

Apesar de parecer algo puramente virtual, a rede depende de uma infraestrutura física gigante: data centers, roteadores, servidores e cabos submarinos de fibra óptica.

🌊 Fato rápido: Cabos no fundo do oceano transportam a maior parte dos dados entre continentes por terem muito mais velocidade e menor latência que satélites!

#WEB

CLIENTE-SERVIDOR & TIM BERNERS-LEE

No fim dos anos 80 no CERN, Tim Berners-Lee criou a World Wide Web (WWW) inventando três pilares: HTML (páginas), HTTP (protocolo) e URL (endereços).

Quando você abre um link, seu navegador (Cliente) faz uma requisição HTTP e o Servidor devolve a página em milissegundos!

#INTERNET

INTERNET X WEB: NÃO CONFUNDA!

INTERNET = A estrada física e lógica global (cabos, roteadores, redes interligadas).

WEB (WWW) = Um dos serviços que trafegam nessa estrada, formado por documentos e sites conectados por hiperlinks.
