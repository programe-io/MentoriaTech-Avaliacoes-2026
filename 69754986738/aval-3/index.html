Principais Tipos de Listas em HTML

1. Lista Não Ordenada (<ul>)

Usada para itens sem uma ordem específica (exibidos com marcadores):

<ul>
    <li>Item um</li>
    <li>Item dois</li>
    <li>Item três</li>
</ul>

Resultado visual:

  • Item um
  • Item dois
  • Item três

2. Lista Ordenada (<ol>)

Usada quando a sequência ou numeração é importante:

<ol>
    <li>Primeiro passo</li>
    <li>Segundo passo</li>
    <li>Terceiro passo</li>
</ol>

Resultado visual:

  1. Primeiro passo
  2. Segundo passo
  3. Terceiro passo

3. Lista de Definição / Descrição (<dl>)

Usada para termos e suas respectivas descrições:

<dl>
    <dt>HTML</dt>
    <dd>Linguagem de marcação para a web.</dd>
    <dt>CSS</dt>
    <dd>Linguagem de estilização.</dd>
</dl>

Resultado visual:

HTML
Linguagem de marcação para a web.
CSS
Linguagem de estilização.
