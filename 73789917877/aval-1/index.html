📝 Revisão de JavaScript (Parte 1)

Resumo estruturado dos fundamentos essenciais

1. Tipos de Dados e typeof

O JavaScript possui tipos dinâmicos para representar diferentes categorias de informação:

  • String: Textos delimitados por aspas simples, duplas ou crase.
  • Number: Representa números inteiros (ex: 10) e reais/decimais (ex: 10.5) dentro da mesma categoria.
  • Boolean: Valores lógicos: true (verdadeiro) ou false (falso).
  • Undefined: Variável declarada, mas que ainda não recebeu nenhum valor.
  • Null: Ausência intencional de valor. (Nota: typeof null retorna "object" por motivos históricos).
  • NaN (Not a Number): Uma condição do tipo número que ocorre quando uma operação matemática falha em gerar um número válido.
  • typeof: Operador usado para verificar o tipo de dado de uma variável ou valor.

2. Strings e Interpolação

  • Crase (``): Permite a criação de Template Strings.
  • Interpolação: A sintaxe ${variavel} dentro de strings com crase insere dinamicamente o valor no texto. Se usada com aspas simples ou duplas, a sintaxe é lida apenas como texto literal.

3. Variáveis e Escopo (var, let, const)

Modo Escopo Reatribuição Comportamento / Recomendação
var Global/Função Permitida Sofre içamento (hoisting) e foge de blocos. Evitar o uso.
let Bloco { } Permitida Ideal para valores que precisam mudar. Recomendado.
const Bloco { } Proibida Ideal para valores fixos (gera erro se reatribuída). Recomendado.
⚠️ Aviso importante: Criar variáveis sem declarar var, let ou const é considerado uma prática inadequada.

4. Categorias de Operadores

Aritméticos (Cálculos)

  • Básicos: Adição (+), Subtração (-), Multiplicação (*), Divisão (/).
  • Avançados: Exponenciação (**) e Resto da divisão (%).
  • Precedência: Multiplicações/divisões ocorrem antes de adições/subtrações. Use parênteses ( ) para modificar a ordem.
  • Incremento (++) e Decremento (--): O pré-incremento altera o valor antes de ler a linha; o pós-incremento altera o valor após a leitura da linha.

Relacionais (Comparações)

  • Retornam sempre um valor booleano (true ou false).
  • Igualdade Ampla (==): Compara apenas o valor (ex: 10 == "10" é true).
  • Igualdade Estrita (===): Compara o valor e o tipo de dado (ex: 10 === "10" é false). Mais seguro e recomendado.
  • Outros: Diferença (!= e !==), Maior que (>), Menor que (<), Maior ou igual (>=), Menor ou igual (<=).

Lógicos (Combinações)

  • E lógico (&&): Retorna verdadeiro apenas se todas as condições forem verdadeiras.
  • OU lógico (||): Retorna verdadeiro se pelo menos uma condição for verdadeira.
  • NOT lógico (!): Inverte o valor lógico atual.

5. Estruturas de Controle (Seleção)

Estrutura if, else if e else

Trabalha avaliando condições lógicas:

  • if: Executa o bloco se a condição for verdadeira.
  • else if: Introduz uma nova condição caso as anteriores tenham falhado.
  • else: Bloco de escape executado apenas se nenhuma condição anterior for atendida.

Estrutura switch case

Trabalha comparando o valor exato de uma variável com múltiplos casos fixos:

  • case: Cada um dos valores possíveis testados.
  • break: Comando obrigatório para impedir que o código continue executando os casos abaixo de forma involuntária.
  • default: Executado se o valor não corresponder a nenhum caso. O break aqui é opcional se colocado ao final.
