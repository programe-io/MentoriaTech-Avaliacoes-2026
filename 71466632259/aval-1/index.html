Bem-vindo ao Meu Site

Um modelo de página HTML5 completo e limpo.

Sobre este código

Este é um exemplo de documento HTML estruturado corretamente. Ele inclui tags semânticas como <header>, <main> e <footer>, que ajudam os motores de busca (como o Google) e os leitores de tela a entenderem a página.

Principais Elementos Utilizados:

  • DOCTYPE html: Informa ao navegador que estamos usando o HTML5.
  • Meta Viewport: Garante que o site fique bonito tanto no computador quanto no celular.
  • CSS Estruturado: Um design básico incluso na tag <style> para melhorar o visual.
