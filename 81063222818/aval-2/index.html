Introdução

HTML é utilizado para estruturar o conteúdo de uma página, enquanto CSS é utilizado para definir sua aparência visual.

Com essas duas tecnologias podemos criar páginas organizadas, estilizadas e acessíveis.

Principais conceitos de HTML

Tags semânticas

  • header - cabeçalho da página
  • main - conteúdo principal
  • section - seção de conteúdo
  • footer - rodapé

Elementos de texto

  1. Títulos com h1 até h6
  2. Parágrafos com p
  3. Links com a
  4. Listas com ul, ol e li

HTML e CSS

O HTML define a estrutura da página e o CSS controla sua apresentação visual.
