Início Sobre HTML CSS

Início

Seja bem-vindo ao meu blog! Este espaço foi criado para apresentar um exemplo de página desenvolvida com HTML e CSS. Aqui você encontrará informações sobre essas tecnologias e sua importância no desenvolvimento de sites.

Sobre

Meu nome é Maely. Este blog foi desenvolvido como atividade da Mentoria Tech com o objetivo de praticar a criação de páginas utilizando HTML para estruturar o conteúdo e CSS para definir o estilo e a aparência da página.

HTML

O HTML é responsável pela estrutura e pelo conteúdo da página, organizando textos, títulos, imagens e outros elementos.

CSS

O CSS é responsável pelo design da página, definindo cores, fontes, tamanhos, espaçamentos e outros estilos visuais.
