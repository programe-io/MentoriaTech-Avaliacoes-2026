Vamos criar um exemplo de código CSS (Cascading Style Sheets) e explicar cada parte para você aprender como funciona. O CSS é uma linguagem utilizada para estilizar páginas HTML, adicionando cores, tamanhos, fontes, espaçamentos, animações e muito mais. 1. Exemplo de código CSS Vamos criar um estilo para uma página com fundo colorido, título, parágrafo e botão. css /* Estilo geral da página */ body { background-color: #e6f2ff; font-family: Arial, sans-serif; text-align: center; margin: 0; padding: 40px; } /* Estilo do título */ h1 { color: #0066cc; font-size: 36px; } /* Estilo do parágrafo */ p { color: #333333; font-size: 18px; } /* Estilo do botão */ button { background-color: #0066cc; color: white; border: none; padding: 12px 25px; border-radius: 8px; cursor: pointer; } /* Efeito ao passar o mouse */ button:hover { background-color: #003366; } 2. Explicação de cada comando Código CSS Explicação body Define o estilo geral da página. background-color Define a cor de fundo. font-family Escolhe o tipo de letra. text-align Alinha o texto. margin Define a margem externa. padding Define o espaçamento interno. color Define a cor do texto. font-size Define o tamanho da fonte. border Define a borda. border-radius Arredonda os cantos. cursor Altera o formato do cursor. :hover Aplica um efeito quando o mouse passa sobre o elemento. 3. Como funciona a estrutura do CSS? Observe este exemplo: css h1 { color: red; font-size: 30px; } Ele possui três partes: h1: seletor, indica qual elemento HTML será estilizado. color: propriedade, indica o que será alterado. red: valor, indica como será a alteração. 4. Como conectar CSS ao HTML? Você pode criar dois arquivos: index.html — contém a estrutura da página. style.css — contém a aparência da página. Dentro do HTML, coloque no <head>: <link rel="stylesheet" href="style.css"> Assim, o HTML utilizará os estilos definidos no CSS. 5. O que você pode aprender em CSS?
