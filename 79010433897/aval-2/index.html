Conhecendo HTML, CSS, domínio e hospedagem

3. Estrutura inicial do projeto

Um projeto web utiliza arquivos que trabalham juntos para construir uma página. Dois arquivos principais são o index.html e o style.css.

O arquivo index.html é responsável pela estrutura e pelo conteúdo da página, incluindo títulos, textos e links. Já o arquivo style.css define a aparência visual, como cores, fontes, tamanhos e espaçamentos.

O nome index.html é uma convenção utilizada para identificar o arquivo principal de um projeto. Os nomes style.css e styles.css são comuns para o arquivo responsável pelos estilos.

Domínio e hospedagem

Durante o desenvolvimento de um site, é importante entender a diferença entre trabalhar com arquivos localmente e disponibilizar uma página na internet.

O domínio é o endereço utilizado pelas pessoas para localizar e acessar um site na internet, como www.exemplo.com.br.

A hospedagem é o serviço que armazena os arquivos do projeto e permite que eles sejam acessados pela internet.

Portanto, o domínio funciona como o endereço do site, enquanto a hospedagem representa o local onde os arquivos ficam armazenados e disponíveis.

Conclusão

Compreender a função dos arquivos HTML e CSS, assim como os conceitos de domínio e hospedagem, é fundamental para criar e publicar páginas web. Esses elementos formam a base para o desenvolvimento de sites acessíveis pela internet.
