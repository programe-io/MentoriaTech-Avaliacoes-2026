O CSS é uma linguagem utilizada para estilizar páginas HTML, modificando cores, tamanhos, fontes, posicionamentos, animações e muito mais. 1. Exemplo de código CSS Vamos criar um cartão moderno com fundo colorido, título, texto e botão. css /* Configuração geral da página */ body { background-color: #e8f0fe; font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; height: 100vh; margin: 0; } /* Estilização do cartão */ .card { background-color: white; width: 300px; padding: 30px; border-radius: 15px; text-align: center; box-shadow: 0 5px 15px rgba(0, 0, 0, 0.2); } /* Estilização do título */ .card h1 { color: #2563eb; font-size: 26px; } /* Estilização do parágrafo */ .card p { color: #555; font-size: 16px; line-height: 1.5; } /* Estilização do botão */ .card button { background-color: #2563eb; color: white; padding: 12px 25px; border: none; border-radius: 8px; cursor: pointer; } /* Efeito ao passar o mouse */ .card button:hover { background-color: #1e40af; } 2. Como funciona a estrutura CSS? Observe: css h1 { color: red; font-size: 30px; } h1: seletor, indica qual elemento será modificado. { }: delimitam as configurações. color: propriedade. red: valor da propriedade. ;: finaliza uma declaração. 4. Como conectar CSS ao HTML? Você pode criar dois arquivos: index.html style.css Dentro do HTML, coloque no <head>: <link rel="stylesheet" href="style.css"> Assim, o HTML utiliza os estilos definidos no CSS. 5. Vamos praticar! Anúncio crie um codigo em JavaScript com explicaçao Claro! 😊 Vamos aprender JavaScript do zero, com exemplos e explicações de cada comando. O JavaScript é uma linguagem de programação que permite adicionar interatividade aos sites, como botões, cálculos, mensagens, jogos e sistemas. 1. Primeiro código em JavaScript Vamos criar um programa que pede o nome do usuário e mostra uma mensagem de boas-vindas. javascript // Pedir o nome do usuário let nome = prompt("Qual é o seu nome?"); // Mostrar uma mensagem alert("Olá, " + nome + "! Seja bem-vindo!"); // Mostrar no console console.log("O usuário entrou no sistema."); Explicação: let: cria uma variável. nome: é o nome da variável. prompt(): abre uma caixa para digitar informações. alert(): mostra uma mensagem na tela. console.log(): mostra informações no console do navegador. 2. Variáveis em JavaScript As variáveis armazenam informações. javascript let nome = "João"; let idade = 20; let altura = 1.75; console.log(nome); console.log(idade); console.log(altura); Existem três formas comuns de declarar variáveis: Comando Significado let Variável que pode mudar const Variável que não pode ser reatribuída var Forma antiga de declarar variáveis 3. Condições (if e else) As condições permitem que o programa tome decisões. javascript let idade = 18; if (idade >= 18) { console.log("Você é maior de idade."); } else { console.log("Você é menor de idade."); } Explicação: if: verifica uma condição. else: executa outra opção se a condição for falsa. >=: significa maior ou igual. 4. Repetições (for) O for permite repetir comandos várias vezes. javascript for (let i = 1; i <= 5; i++) { console.log("Número: " + i); } Resultado: text Número: 1 Número: 2 Número: 3 Número: 4 Número: 5 5. Funções As funções são blocos de código que executam tarefas. javascript function somar(a, b) { return a + b; } let resultado = somar(10, 5); console.log("Resultado: " + resultado); Resultado: 15. function: cria uma função. a e b: recebem os valores. return: devolve o resultado. somar(10, 5): executa a função. 6. Exemplo prático: calculadora Agora vamos juntar o que aprendemos para criar uma calculadora simples. javascript let numero1 = Number(prompt("Digite o primeiro número:")); let numero2 = Number(prompt("Digite o segundo número:")); let operacao = prompt("Escolha: +, -, * ou /"); let resultado; if (operacao === "+") { resultado = numero1 + numero2; } else if (operacao === "-") { resultado = numero1 - numero2; } else if (operacao === "*") { resultado = numero1 * numero2; } else if (operacao === "/") { if (numero2 !== 0) { resultado = numero1 / numero2; } else { alert("Não é possível dividir por zero!"); } } else { alert("Operação inválida!"); } if (resultado !== undefined) { alert("Resultado: " + resultado); } 7.
