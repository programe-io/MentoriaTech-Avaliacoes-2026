Guia de Revisão

Conceitos essenciais de HTML e CSS para iniciar seus estudos.

1. Estrutura Básica do HTML

O HTML define o esqueleto da página web utilizando tags como <head> para metadados e <body> para o conteúdo visível.

2. Seletores do CSS

Utilizados para encontrar e estilizar os elementos HTML:

  • Por Tag: ex. h1
  • Por Classe: ex. .card
  • Por ID: ex. #topo

3. O Modelo de Caixa (Box Model)

Cada elemento na Web é uma caixa composta por: Margem (margin), Borda (border), Preenchimento (padding) e o Conteúdo.
