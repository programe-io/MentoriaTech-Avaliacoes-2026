1. O que é a Internet?

A Internet é uma rede mundial de computadores interligados que permite a comunicação e a troca de informações.

Características da Internet

  • Conecta bilhões de dispositivos.
  • Utiliza protocolos de comunicação.
  • Permite compartilhar informações.
  • Possibilita serviços online.

História da Internet

  1. Década de 1960: criação da ARPANET.
  2. Década de 1970: desenvolvimento do TCP/IP.
  3. Década de 1980: expansão acadêmica.
  4. Década de 1990: popularização comercial.

Infraestrutura da Internet

  • Servidores.
  • Data centers.
  • Roteadores.
  • Cabos de fibra óptica.
  • Satélites.

2. O que é a Web?

A World Wide Web é um sistema de documentos interligados por hiperlinks que funciona sobre a infraestrutura da Internet.

Como funciona a Web?

  1. O usuário acessa um endereço.
  2. O navegador envia uma requisição.
  3. O servidor recebe a solicitação.
  4. O servidor envia os dados.
  5. O navegador apresenta a página.

Internet x Web

Internet: infraestrutura de comunicação.

Web: serviço de páginas e documentos.

Tim Berners-Lee

Tim Berners-Lee criou a World Wide Web no CERN, no final da década de 1980. Entre as tecnologias fundamentais da Web estão HTML, HTTP e URL.

3. Introdução ao HTML

HTML é uma linguagem de marcação utilizada para estruturar o conteúdo de uma página.

Principais tags HTML

  • h1 até h6: títulos.
  • p: parágrafos.
  • a: links.
  • img: imagens.
  • ul: lista não ordenada.
  • ol: lista ordenada.
  • li: item de lista.
  • div: divisão genérica.
  • header: cabeçalho.
  • main: conteúdo principal.
  • section: seção de conteúdo.
  • footer: rodapé.

Estrutura básica HTML

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Minha página</title>
</head>
<body>
    <h1>Olá, mundo!</h1>
    <p>Minha primeira página.</p>
</body>
</html>

4. Introdução ao CSS

CSS é utilizado para definir a aparência visual dos elementos HTML.

Seletores e propriedades

  • color: cor do texto.
  • background-color: cor de fundo.
  • font-size: tamanho da fonte.
  • text-align: alinhamento do texto.
  • width: largura.
  • height: altura.
  • border: borda.
  • margin: espaçamento externo.
  • padding: espaçamento interno.

Exemplo CSS

body {
    background-color: #f1f5f9;
    color: #1e293b;
    font-family: Arial;
}

h1 {
    color: blue;
    text-align: center;
}

Box Model

Conteúdo HTML

Margin: espaço externo.

Border: borda do elemento.

Padding: espaço interno.

Content: conteúdo do elemento.
