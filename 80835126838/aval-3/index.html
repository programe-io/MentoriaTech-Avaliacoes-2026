1. Introdução

A internet e a web estão tão presentes no cotidiano que muitas vezes utilizamos essas tecnologias sem realmente compreender como elas funcionam.

Todos os dias acessamos sites, assistimos vídeos, utilizamos redes sociais e trocamos informações online. No entanto, por trás dessas atividades existe uma infraestrutura tecnológica complexa que conecta bilhões de dispositivos em todo o mundo.

Este material tem como objetivo apresentar os conceitos fundamentais que explicam o funcionamento da internet e da web.

Durante este estudo, veremos:

  • O que é a internet;
  • Como ela surgiu;
  • Como os computadores se comunicam;
  • O que é a web;
  • Como a web funciona sobre a internet.

2. O que é a Internet

A internet pode ser definida como um sistema global de redes de computadores interligadas.

Essas redes se comunicam utilizando um conjunto padronizado de regras chamado protocolos de comunicação. Esses protocolos permitem que dispositivos diferentes, como computadores, celulares e servidores, consigam trocar informações entre si.

Internet: uma enorme infraestrutura de comunicação digital que conecta dispositivos ao redor do mundo.

Características principais:

  • É uma rede mundial de redes;
  • Conecta bilhões de dispositivos;
  • Utiliza protocolos padronizados;
  • Permite o compartilhamento de informações.

Principais usos:

  • Comunicação por e-mail e mensagens;
  • Acesso a sites;
  • Streaming de vídeo e áudio;
  • Serviços online;
  • Computação em nuvem.

3. História da Internet

A origem da internet remonta à década de 1960, durante um período marcado pela Guerra Fria e pela necessidade de sistemas de comunicação mais seguros.

Nesse contexto surgiu a ARPANET, um projeto desenvolvido pelo Departamento de Defesa dos Estados Unidos.

O objetivo inicial era criar uma rede que permitisse a comunicação entre centros de pesquisa e instituições militares.

Principais características da ARPANET:

  • Comunicação descentralizada;
  • Compartilhamento de recursos computacionais;
  • Conexão entre universidades e centros de pesquisa.

Marcos importantes:

  • Década de 1960: criação da ARPANET;
  • Década de 1970: desenvolvimento dos protocolos TCP/IP;
  • Década de 1980: expansão da rede para universidades;
  • Década de 1990: popularização da internet comercial.

4. Infraestrutura da Internet

Embora muitas pessoas imaginem a internet como algo virtual, ela depende de uma grande infraestrutura física.

Essa infraestrutura inclui:

  • Data centers;
  • Servidores;
  • Cabos de fibra óptica;
  • Roteadores;
  • Satélites;
  • Equipamentos de rede.

Quando um usuário acessa um site, seu dispositivo envia uma solicitação pela rede. Essa solicitação percorre diversos equipamentos até chegar ao servidor que hospeda o conteúdo.

O servidor então responde enviando os dados de volta ao dispositivo do usuário.

5. Cabos Submarinos de Internet

Grande parte da comunicação global da internet ocorre por meio de cabos submarinos de fibra óptica.

Esses cabos atravessam oceanos e conectam continentes inteiros, transportando enormes quantidades de dados entre países e regiões do mundo.

Características dos cabos submarinos:

  • Percorrem milhares de quilômetros;
  • Utilizam tecnologia de fibra óptica;
  • Possuem alta capacidade de transmissão de dados;
  • Conectam diferentes continentes.

Apesar da existência de satélites, a maior parte do tráfego internacional de dados acontece através desses cabos.

6. O que é a Web (World Wide Web)

A World Wide Web, ou simplesmente Web, é um sistema que funciona sobre a internet.

Ela consiste em um conjunto de documentos interligados por meio de hiperlinks.

Esses documentos podem incluir:

  • Textos;
  • Imagens;
  • Vídeos;
  • Sons;
  • Animações.

Quando um usuário acessa um site, ele está navegando por documentos que fazem parte da Web.

7. Como funciona a Web

A Web funciona com base em uma arquitetura chamada cliente-servidor.

Cliente

O cliente é o dispositivo utilizado pelo usuário para acessar a Web.

  • Computador;
  • Smartphone;
  • Tablet.

Normalmente, o cliente utiliza um navegador web, como Chrome, Firefox, Edge ou Safari.

Servidor

O servidor é o computador responsável por armazenar e fornecer os conteúdos dos sites.

Etapas do funcionamento:

  1. O navegador envia uma requisição ao servidor;
  2. O servidor processa a solicitação;
  3. O servidor envia os dados de volta;
  4. O navegador exibe o conteúdo ao usuário.
Esse processo ocorre por meio de protocolos de comunicação, especialmente o HTTP (Hypertext Transfer Protocol).

8. O papel de Tim Berners-Lee

O cientista da computação Tim Berners-Lee foi o criador da World Wide Web.

Ele desenvolveu a Web no final da década de 1980 enquanto trabalhava no CERN, um grande centro de pesquisa científica na Europa.

O objetivo era facilitar o compartilhamento de informações entre pesquisadores.

Três tecnologias fundamentais:

  • HTML: linguagem de marcação para criação de páginas.
  • HTTP: protocolo de comunicação da Web.
  • URL: sistema de endereçamento de recursos na internet.

9. Internet x Web: diferenças fundamentais

Um erro comum é considerar internet e Web como se fossem a mesma coisa. Na realidade, são conceitos diferentes.

Internet

É a infraestrutura de rede global que conecta computadores e permite a comunicação entre dispositivos.

Web

É um dos serviços que utilizam a internet. Ela consiste em páginas e documentos interligados acessados por navegadores.

Outros serviços que utilizam a internet:

  • E-mail;
  • Transferência de arquivos (FTP);
  • Streaming;
  • Jogos online;
  • Serviços em nuvem.

Internet = infraestrutura de comunicação.

Web = sistema de páginas e documentos sobre essa infraestrutura.

10. Conclusão

A internet é uma das tecnologias mais importantes já criadas, permitindo a comunicação global e o acesso rápido à informação.

Ela surgiu como um projeto militar e acadêmico, mas evoluiu para uma rede mundial que conecta bilhões de pessoas e dispositivos.

Sobre essa infraestrutura foi criada a World Wide Web, um sistema de documentos interligados que tornou o acesso à informação simples e acessível.

Compreender os conceitos fundamentais de internet e web é essencial para qualquer pessoa que deseja trabalhar com tecnologia, especialmente nas áreas de desenvolvimento web, redes de computadores e sistemas distribuídos.
