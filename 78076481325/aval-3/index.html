NOSSA PROPOSTA

Como o Nutri+ pode ajudar?

Organizar a merenda escolar envolve várias tarefas, desde o controle dos alimentos até o registro das refeições servidas. Reunir essas informações em um sistema pode tornar esse trabalho mais prático.

FUNCIONALIDADES

Recursos do projeto

01

Registro de alunos

Auxilia no registro dos estudantes atendidos durante a merenda.

02

Controle de estoque

Ajuda a acompanhar os alimentos disponíveis para as refeições.

03

Histórico diário

Permite consultar os registros das refeições realizadas na escola.
