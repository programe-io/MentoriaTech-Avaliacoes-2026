O que é HTML?

HTML significa HyperText Markup Language. Ele é utilizado para estruturar o conteúdo de páginas web.

Com HTML podemos criar títulos, parágrafos, imagens, links, listas, tabelas, formulários e muito mais.

Principais tags HTML

Pesquise abaixo para encontrar uma tag específica:

<h1>

Cria o título principal de uma página.

<h1>Meu título</h1>

<p>

Cria um parágrafo de texto.

<p>Olá, mundo!</p>

<a>

Cria links para outras páginas.

<a href="https://google.com"> Google </a>

<img>

Adiciona uma imagem à página.

<img src="foto.jpg" alt="Foto">

<ul> + <li>

Criam listas não ordenadas.

<ul>
  <li>Item</li>
</ul>

<button>

Cria um botão interativo.

<button>Clique aqui</button>

<div>

Cria um container para organizar elementos.

<div>Conteúdo</div>

<form>

Usada para criar formulários.

<form>...</form>
