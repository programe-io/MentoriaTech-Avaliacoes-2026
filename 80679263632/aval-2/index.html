Introdução à Web e à Internet

Descubra como funciona a internet, conheça sua história e entenda como a World Wide Web conecta o mundo.

Começar a explorar

01. Introdução

A internet e a web estão presentes em nosso cotidiano. Todos os dias acessamos sites, assistimos vídeos, utilizamos redes sociais e trocamos informações online.

Por trás dessas atividades existe uma infraestrutura tecnológica que conecta bilhões de dispositivos em todo o mundo.

Este estudo apresenta os conceitos fundamentais sobre o funcionamento da internet e da web.

02. O que é a Internet?

A internet é um sistema global de redes de computadores interligadas que permite a comunicação e a troca de informações entre dispositivos.

Principais características:

  • Rede mundial de computadores.
  • Conecta bilhões de dispositivos.
  • Utiliza protocolos de comunicação.
  • Permite o compartilhamento de informações.

Entre seus principais usos estão e-mails, redes sociais, streaming, serviços online e computação em nuvem.

03. História da Internet

A origem da internet começou na década de 1960, durante a Guerra Fria, com a criação da ARPANET, um projeto desenvolvido pelo Departamento de Defesa dos Estados Unidos.

O objetivo era permitir a comunicação entre centros de pesquisa e instituições, mesmo diante de falhas em partes da rede.

Década de 1960

Criação da ARPANET.

Década de 1970

Desenvolvimento dos protocolos TCP/IP.

Década de 1980

Expansão da rede para universidades.

Década de 1990

Popularização da internet comercial.

04. Infraestrutura da Internet

A internet depende de uma grande infraestrutura física para funcionar. Mesmo sendo utilizada de forma virtual, ela precisa de equipamentos e conexões reais.

Data Centers

Locais que armazenam grandes quantidades de dados.

Servidores

Computadores responsáveis por fornecer conteúdos.

Fibra Óptica

Transmite informações utilizando sinais de luz.

Roteadores

Direcionam os dados entre diferentes redes.

05. Cabos Submarinos de Internet

Grande parte da comunicação global acontece por meio de cabos submarinos de fibra óptica, que atravessam oceanos e conectam diferentes continentes.

  • Percorrem milhares de quilômetros.
  • Utilizam tecnologia de fibra óptica.
  • Transportam grandes quantidades de dados.
  • Oferecem alta velocidade e baixa latência.

06. O que é a Web (World Wide Web)?

A World Wide Web, também conhecida como Web, é um sistema de documentos e páginas interligadas por meio de hiperlinks.

Esses documentos podem conter:

  • Textos.
  • Imagens.
  • Vídeos.
  • Sons.
  • Animações.

A Web funciona sobre a infraestrutura da internet e permite acessar sites utilizando navegadores.

07. Como funciona a Web?

A Web utiliza uma arquitetura chamada cliente-servidor. O navegador solicita informações e o servidor responde enviando os dados necessários.

01

Cliente

O usuário acessa um site pelo navegador.

02

Requisição

O navegador envia uma solicitação ao servidor.

03

Servidor

O servidor processa a solicitação.

04

Resposta

O navegador recebe e apresenta o conteúdo.

Esse processo utiliza protocolos de comunicação, especialmente o HTTP.

08. O papel de Tim Berners-Lee

Tim Berners-Lee foi o cientista da computação responsável pela criação da World Wide Web, no final da década de 1980, enquanto trabalhava no CERN, na Europa.

Suas três tecnologias fundamentais:

HTML

Linguagem de marcação utilizada para criar páginas web.

HTTP

Protocolo utilizado na comunicação da Web.

URL

Sistema de endereçamento dos recursos da Web.

09. Internet x Web

Internet e Web são conceitos diferentes, embora estejam diretamente relacionados.

INTERNET

É a infraestrutura global que conecta computadores e dispositivos.

WEB

É um serviço que utiliza a internet para disponibilizar páginas e documentos.

Internet = infraestrutura
Web = páginas e documentos conectados.

10. Conclusão

A internet é uma das tecnologias mais importantes da atualidade, permitindo a comunicação global e o acesso rápido à informação.

A World Wide Web utiliza essa infraestrutura para conectar páginas, documentos e conteúdos acessíveis por navegadores.

Compreender esses conceitos é fundamental para quem deseja estudar desenvolvimento web, redes de computadores e tecnologia.
