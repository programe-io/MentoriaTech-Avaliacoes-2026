A lógica de programação é o primeiro passo para aprender a desenvolver programas, aplicativos e sites. Neste curso, você vai conhecer os principais conceitos da programação e aprender a utilizar JavaScript.

O que é Lógica de Programação?

É a organização de ideias e instruções para resolver problemas de maneira simples e eficiente.

Principais conceitos:

  • Variáveis
  • Operadores matemáticos
  • Estruturas condicionais
  • Estruturas de repetição
  • Algoritmos

O que é um Algoritmo?

Algoritmo é uma sequência de passos organizados para realizar uma tarefa ou resolver um problema. 

INÍCIO
    Ler número 1
    Ler número 2
    Somar os números
    Mostrar resultado
FIM
