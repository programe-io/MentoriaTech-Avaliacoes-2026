Como aprender HTML do zero

HTML é a linguagem utilizada para criar páginas da internet.

HTML significa HyperText Markup Language. É através dele que construímos títulos, textos, imagens, listas, tabelas, formulários e diversos elementos de uma página. Aprender HTML é o primeiro passo para quem deseja se tornar desenvolvedor web.

CSS deixa os sites mais bonitos

Conheça o poder das folhas de estilo.

O CSS controla cores, fontes, animações, espaçamentos e praticamente toda a aparência de um site moderno.

Por que aprender JavaScript?

JavaScript traz vida às páginas.

Com JavaScript podemos criar menus, jogos, animações, formulários inteligentes e diversas funcionalidades para um site.
