Aprendendo lógica de programação

O que é lógica de programação?

A lógica de programação é a organização de ideias e instruções para resolver problemas por meio de um computador.

Principais conceitos

1. Variáveis

Armazenam informações.

let nome = "Maria";

2. Operadores

Realizam cálculos e comparações.

let soma = 10 + 5;

3. Condicionais

Permitem que o programa tome decisões.

if (idade >= 18) { }

4. Funções

Executam tarefas específicas.

function saudacao() { }
