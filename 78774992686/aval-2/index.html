2. O que é a Internet

A internet é um sistema global de redes de computadores interligadas. Elas se comunicam usando um conjunto padronizado de regras chamado protocolos de comunicação.

Esses protocolos garantem que aparelhos totalmente diferentes (PC, celular, servidores) consigam conversar entre si sem erros.

🐺 Características cruciais:

• Rede mundial de redes
• Conecta bilhões de nós
• Compartilhamento de dados global

3. História da Internet

A origem disso tudo remonta à década de 1960, em plena Guerra Fria. O Departamento de Defesa dos EUA criou a ARPANET para ter uma comunicação descentralizada que resistisse a ataques.

Evolução rápida das décadas:

  • 1960: ARPANET operacional
  • 1970: Protocolos TCP/IP criados
  • 1980: Expansão universitária
  • 1990: Boom da internet comercial

4 e 5. Infraestrutura e Cabos Submarinos

A internet não é mágica, ela é física! Depende de imensos data centers, roteadores e, principalmente, de cabos submarinos de fibra óptica que cortam os oceanos conectando continentes.

Eles oferecem muito mais velocidade e menor latência do que os satélites que orbitam a Terra.

6. O que é a Web (World Wide Web)

A Web é apenas um sistema que funciona sobre a internet. Ela é composta pelo conjunto de páginas, mídias e documentos interligados através de hiperlinks.

7. Como funciona a Web

Tudo se resume ao modelo Cliente-Servidor:

Cliente: Seu celular ou computador rodando o navegador (Chrome, Safari, Firefox).
Servidor: A máquina remota que guarda os arquivos do site.

O navegador faz uma requisição HTTP, o servidor processa e devolve a página estruturada.
