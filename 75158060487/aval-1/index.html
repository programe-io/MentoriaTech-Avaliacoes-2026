💡 Sobre o projeto

O Calendário Fácil foi criado como um projeto educacional utilizando HTML para estruturar a página, CSS para personalizar o visual e JavaScript para gerar o calendário interativo.

Planejar as datas ajuda a organizar os estudos, os compromissos e os momentos de lazer.
