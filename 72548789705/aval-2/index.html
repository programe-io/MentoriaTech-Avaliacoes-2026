Simulando um sistema de gerenciamento de tarefas (código, título, prioridade e status de conclusão), crie um algoritmo em JavaScript que permita: Cadastrar uma nova tarefa Listar as tarefas cadastradas Marcar uma tarefa como concluída Alterar a prioridade de uma tarefa Regras de validação: O título deve ter no mínimo 5 caracteres A prioridade deve ser um valor
