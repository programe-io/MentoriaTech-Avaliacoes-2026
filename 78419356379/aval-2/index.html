1. Introdução

Toda vez que você acessa um site, lê uma notícia ou assiste a um vídeo no navegador, está interagindo com uma página construída sobre uma base fundamental: o HTML. Dominar essa tecnologia é o primeiro passo para qualquer pessoa que deseja criar sites e aplicações web.

2. O que é HTML

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). Diferente de linguagens como JavaScript ou Python, o HTML não é uma linguagem de programação — ele não realiza cálculos ou toma decisões lógicas. Ele é uma linguagem de marcação usada para estruturar e dar significado ao conteúdo.

3. A função do HTML na Web

Costuma-se comparar o desenvolvimento web à construção de uma casa:

  • HTML (Estrutura): São as paredes, colunas e o telhado. Define o que é título, parágrafo, imagem ou botão.
  • CSS (Estilo): É a pintura, o piso e a decoração. Cuida das cores, fontes e layout.
  • JavaScript (Comportamento): É a parte elétrica e hidráulica. Faz as coisas funcionarem e interagirem com o usuário.

4. Estrutura básica de um documento HTML

Todo arquivo HTML segue um esqueleto padrão para que o navegador saiba como interpretá-lo:

<!DOCTYPE html>
                                                                                                                                                                                                                                                                                                                                                                                                <html lang="pt-BR">
                                                                                                                                                                                                                                                                                                                                                                                                <head>
                                                                                                                                                                                                                                                                                                                                                                                                  <meta charset="UTF-8">
                                                                                                                                                                                                                                                                                                                                                                                                    <title>Minha Primeira Página</title>
                                                                                                                                                                                                                                                                                                                                                                                                    </head>
                                                                                                                                                                                                                                                                                                                                                                                                    <body>
                                                                                                                                                                                                                                                                                                                                                                                                      <h1>Olá, Mundo!</h1>
                                                                                                                                                                                                                                                                                                                                                                                                        <p>Este é meu primeiro documento HTML.</p>
                                                                                                                                                                                                                                                                                                                                                                                                        </body>
                                                                                                                                                                                                                                                                                                                                                                                                        </html>

5. Elementos e tags HTML

O HTML funciona por meio de tags (etiquetas) escritas entre sinais de menor e maior (< >). A maioria possui uma tag de abertura e uma de fechamento:

<p>Conteúdo do parágrafo</p>

O conjunto formado pela tag de abertura, conteúdo e tag de fechamento chama-se Elemento HTML. Existem também elementos vazios que não precisam de fechamento, como <img> e <br>.

6. Atributos em HTML

Atributos fornecem informações extras sobre um elemento e são sempre definidos na tag de abertura no formato nome="valor":

<a href="https://exemplo.com" target="_blank">Visitar Site</a>
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          <img src="foto.jpg" alt="Descrição da imagem">

7. Principais elementos de conteúdo

  • <h1> a <h6>: Títulos e subtítulos (do mais importante ao menos importante).
  • <p>: Parágrafos de texto.
  • <a>: Links (âncoras) para navegar entre páginas.
  • <img>: Inserção de imagens.
  • <ul>, <ol> e <li>: Listas não ordenadas, ordenadas e itens de lista.
  • <div> e <span>: Contêineres genéricos para agrupar elementos.

8. Hierarquia e organização do documento

Os elementos HTML são aninhados uns dentro dos outros como caixas, formando uma árvore genealógica chamada DOM (Document Object Model). Um elemento dentro de outro é chamado de "filho", e o que o envolve é o "pai".

Além disso, usamos tags semânticas como <header>, <nav>, <main>, <article> e <footer> para organizar o layout com significado claro.

9. Boas práticas na escrita de HTML

  • Use HTML Semântico: Prefira <article> ou <section> em vez de usar <div> para tudo.
  • Indentação: Mantenha o código alinhado com espaços ou tabulações para facilitar a leitura.
  • Acessibilidade: Sempre preencha o atributo alt nas imagens e use um único <h1> por página.
  • Letras minúsculas: Escreva todas as tags e atributos em letras minúsculas.

10. Conclusão

O HTML é a espinha dorsal da web. Embora simples de aprender nos primeiros passos, dominar sua semântica e organização garante sites mais rápidos, acessíveis e bem posicionados nos motores de busca.
