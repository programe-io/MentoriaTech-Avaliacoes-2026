ARRAY

Estrutura de dados utilizada para armazenar vários valores em uma única variável.

🔹 O que é?

Um array é uma estrutura que armazena uma coleção de elementos, normalmente do mesmo tipo, organizados em posições.

🔹 Características

  • Possui várias posições.
  • Cada posição possui um índice.
  • O índice geralmente começa em 0.
  • Permite acessar elementos rapidamente.

💡 Para que serve?

Arrays são úteis para armazenar listas de números, nomes, notas, produtos e outros dados que precisam ser organizados e acessados por posição.

20

40
50
