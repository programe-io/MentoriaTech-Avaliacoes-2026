TIPOS DE DADOS

Definem que tipo de informação uma variável pode armazenar.

🔹 O que são?

Tipos de dados determinam quais valores podem ser armazenados em uma variável e quais operações podem ser realizadas com esses valores.

🔹 Por que são importantes?

Eles ajudam o programa a organizar os dados corretamente, evitando erros e permitindo que o computador saiba como tratar cada informação.

📊 Principais tipos de dados

Tipo Representa Exemplo
int Números inteiros 10, -5, 100
float Números decimais 3.14, 2.5
char Um caractere 'A', 'B'
string Texto "Olá"
boolean Verdadeiro ou falso true / false
Exemplo:
int idade = 18;    string nome = "João";
