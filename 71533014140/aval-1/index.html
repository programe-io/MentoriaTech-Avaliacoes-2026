Curso de JavaScript

Fundamentos de Lógica de Programação

1. Introdução

Esta formação apresenta os fundamentos da lógica de programação utilizando JavaScript.

O objetivo é desenvolver o raciocínio lógico necessário para criar algoritmos e resolver problemas através da programação.

2. Objetivos da Formação

  • Aprender os fundamentos do JavaScript.
  • Desenvolver raciocínio lógico.
  • Criar algoritmos passo a passo.
  • Resolver problemas utilizando programação.

3. Conteúdos que serão estudados

Tipos de dados

Texto, números, booleanos e outros tipos.

Variáveis

Armazenamento e manipulação de informações.

Operadores

Cálculos e comparações.

Condições

Controle do fluxo do programa.

Repetições

Execução de comandos várias vezes.

Funções

Organização e reutilização de código.

Estruturas de dados

Organização de conjuntos de informações.

4. Ambiente de Desenvolvimento

Durante o curso podemos utilizar diferentes ambientes para escrever e executar JavaScript.

Visual Studio Code

Editor utilizado para criar e organizar os arquivos do projeto.

Node.js

Permite executar JavaScript diretamente no computador.

Programiz

Ambiente online para testar códigos JavaScript diretamente no navegador.

10. Primeiro arquivo JavaScript

No Visual Studio Code podemos criar um arquivo chamado: 

exemplo1.js

Dentro dele podemos escrever: 

console.log("Olá, mundo");

Para executar pelo terminal usando Node.js: 

node exemplo1.js

11. Boas Práticas Iniciais

  • Organize seus arquivos em pastas.
  • Utilize nomes claros para variáveis.
  • Salve os arquivos antes de executar.
  • Utilize a extensão .js nos arquivos JavaScript.
  • Faça testes pequenos durante o desenvolvimento.

12. Conclusão

Nesta primeira aula conhecemos o JavaScript, seus principais conceitos e os ambientes utilizados para desenvolver os códigos.

Agora podemos avançar para os fundamentos da linguagem e começar a desenvolver algoritmos mais completos.
