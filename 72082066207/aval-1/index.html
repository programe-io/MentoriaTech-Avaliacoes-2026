2. Revisão dos Tipos de Dados

O JavaScript trabalha com diferentes tipos para representar textos, números, valores lógicos e estados especiais[cite: 1, 2].

String

Utilizado para armazenar textos, escritos com aspas simples, duplas ou crase[cite: 1, 9].

let nome = "JavaScript";

Number

Engloba tanto números inteiros quanto decimais (com ponto flutuante)[cite: 1, 2, 9].

let idade = 25; let preco = 10.5;

Boolean

Representa valores lógicos: verdadeiro (true) ou falso (false)[cite: 2, 9].

let ativo = true;

Undefined & Null

Undefined indica valor não atribuído. Null é a ausência intencional de valor[cite: 2, 9].

let resposta = null;

NaN (Not-a-Number)

Valor especial do tipo number resultante de operações matemáticas inválidas[cite: 2, 9].

let erro = "texto" / 2;

4. Declaração de Variáveis: var, let e const

Conheça as três formas de declarar variáveis e suas diferenças de escopo:

Palavra-chave Escopo / Comportamento Recomendação
var Antigo, sofre içamento (hoisting) para escopos anteriores[cite: 2, 3, 10]. Menos recomendada
let Escopo de bloco restrito. Ideal para valores que mudam[cite: 3, 10]. Recomendada
const Escopo de bloco restrito. O valor atribuído não pode ser alterado[cite: 3, 10]. Recomendada para constantes
