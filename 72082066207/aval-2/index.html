1. Estruturas de Repetição (Loops)

Utilizadas para executar blocos de código repetidamente enquanto uma condição for satisfeita[cite: 12].

Loop for

Utilizado quando sabemos exatamente quantas vezes o bloco deve se repetir[cite: 12].

for(let i=0; i<5; i++) { ... }

Loop while

Repete enquanto a condição for verdadeira, fazendo o teste lógico no início[cite: 12].

while(condicao) { ... }

Loop do...while

Garante que o bloco seja executado ao menos uma vez antes de testar a condição[cite: 12].

do { ... } while(condicao);

2. Declaração de Funções

O JavaScript oferece diferentes formas de estruturar blocos reutilizáveis de código[cite: 14]:

Tipo de Função Descrição / Sintaxe
Function Declaration Declaração tradicional nomeada: function somar(a, b) { return a + b; }[cite: 14]
Function Expression Atribuída a uma variável: const somar = function(a, b) { return a + b; };[cite: 14]
Arrow Functions Sintaxe moderna e compacta: const somar = (a, b) => a + b;[cite: 14]
Anonymous Functions Funções sem nome próprio, muito usadas como argumentos (ex: callbacks)[cite: 14].

3. Arrays (Vetores)

Coleções ordenadas de valores armazenados em uma única variável indexada[cite: 15]:

Indexação Zero

O primeiro elemento do array está sempre posicionado no índice 0, o segundo no 1, e assim por diante[cite: 15].

Dinâmicos & Heterogêneos

Você pode alterar o tamanho livremente e misturar diferentes tipos de dados (números, strings, objetos) no mesmo array[cite: 15].
