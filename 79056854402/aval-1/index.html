Introdução à Web e Internet

O que é a Internet?

A Internet é uma rede global de computadores conectados entre si, permitindo a troca de informações em tempo real. Ela possibilita comunicação, entretenimento, educação e acesso a diversos serviços digitais.

O que é a Web?

A Web (World Wide Web) é um dos principais serviços da Internet. Ela permite acessar páginas e aplicações por meio de navegadores como Chrome, Firefox e Edge.

As páginas web são construídas utilizando tecnologias como HTML, CSS e JavaScript.
