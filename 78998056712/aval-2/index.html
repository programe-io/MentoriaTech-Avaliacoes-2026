Este é um modelo interativo. Clique no botão abaixo para alternar o tema da página.

Como funciona: CSS define dois temas: claro (padrão) e escuro (body.dark). JavaScript alterna a classe dark no quando o botão é clicado. Transições suaves deixam a mudança de tema mais agradável. Se quiser, posso melhorar para salvar a preferência do usuário no navegador usando localStorage, assim o tema escolhido permanece mesmo após recarregar a página. Quer que eu já adicione essa melhoria?
