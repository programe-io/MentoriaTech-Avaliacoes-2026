Somando os N primeiros números pares

Sobre o Exercício

O objetivo deste exercício é ler um número inteiro N e calcular a soma dos N primeiros números pares utilizando a linguagem JavaScript.

O programa utiliza estruturas de repetição, operadores matemáticos e variáveis para realizar o cálculo automaticamente.
