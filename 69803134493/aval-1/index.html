Questionário - Projeto Meu Blog

1. Qual seção de um blog normalmente contém informações adicionais, links ou categorias?

A. Cabeçalho

B. Script

C. Rodapé

D. Conteúdo principal

E. Barra lateral

Resposta: E. Barra lateral

2. Por que o desenvolvimento do projeto é feito de forma progressiva?

A. Para eliminar o uso de HTML

B. Para aumentar a velocidade da internet

C. Para criar vários servidores diferentes

D. Para substituir o CSS

E. Para permitir melhorias gradativas enquanto novos conceitos são aprendidos

Resposta: E

3. Por que é importante testar frequentemente a página no navegador durante o desenvolvimento?

A. Para verificar como o layout está sendo exibido

B. Para criar banco de dados automaticamente

C. Para substituir o CSS

D. Para controlar servidores

E. Para aumentar a velocidade da internet

Resposta: A

4. Qual é um dos principais benefícios de desenvolver um projeto completo como um blog durante o curso?

A. Substituir todas as tecnologias web

B. Criar servidores automaticamente

C. Aplicar na prática os conhecimentos adquiridos

D. Eliminar o uso de CSS

E. Controlar redes de computadores

Resposta: C

5. Qual elemento representa o conteúdo principal de um blog?

A. Scripts do navegador

B. Posts ou artigos publicados

C. Configuração de rede

D. Servidores web

E. Protocolos de internet

Resposta: B

6. Qual tecnologia pode ajudar a organizar melhor o layout da página durante o desenvolvimento do blog?

A. Flexbox

B. Banco de dados

C. Protocolo HTTP

D. Sistema operacional

E. Navegador

Resposta: A

7. Qual é um dos objetivos de aplicar CSS ao projeto do blog?

A. Criar banco de dados

B. Criar servidores web

C. Substituir o HTML

D. Melhorar a aparência visual da página

E. Controlar a internet

Resposta: D

8. Por que é importante ajustar cores, fontes e espaçamentos durante o desenvolvimento do blog?

A. Para aumentar a velocidade da internet

B. Para melhorar a organização visual e a experiência do usuário

C. Para substituir o HTML

D. Para criar banco de dados

E. Para controlar servidores

Resposta: B

9. Qual é o principal objetivo da segunda parte do projeto "Meu Blog"?

A. Criar um banco de dados para o site

B. Criar um sistema operacional

C. Continuar o desenvolvimento do blog e melhorar sua estrutura e aparência

D. Substituir o HTML por CSS

E. Criar um servidor web

Resposta: C

10. Qual problema pode ocorrer se o layout da página não for bem ajustado?

A. O servidor será desligado

B. O navegador será removido

C. O HTML deixará de funcionar

D. O site pode ficar desorganizado e difícil de navegar

E. O CSS será apagado

Resposta: D
