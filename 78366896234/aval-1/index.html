Início Sobre HTML Tags Exemplos

🌐 O que é HTML?

HTML significa HyperText Markup Language, ou Linguagem de Marcação de Hipertexto.

É uma linguagem utilizada para criar a estrutura de páginas da internet, como textos, imagens, links e tabelas.

📚 Principais tags HTML

<h1> - Cria um título.

<p> - Cria um parágrafo.

<img> - Adiciona uma imagem.

<a> - Cria um link.

<br> - Faz uma quebra de linha.

<ul> - Cria uma lista.

💻 Primeiro código HTML

Veja um exemplo simples de como criar uma página HTML:

<!DOCTYPE html>
<html>
<head>
  <title>Minha página</title>
</head>
<body>
  <h1>Olá, mundo!</h1>
  <p>Meu primeiro site!</p>
</body>
</html>

🚀 Por que aprender HTML?

Aprender HTML é o primeiro passo para desenvolver sites e entrar no mundo da programação.

Com HTML, CSS e JavaScript você pode criar páginas modernas e interativas!
