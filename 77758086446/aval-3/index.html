Display, Visibilidade e Dark Mode

Aprendendo recursos do CSS

1. O que é Display?

A propriedade display define como um elemento aparece e ocupa espaço na página.

display: block;

O elemento ocupa uma linha inteira.

display: inline; Este elemento ocupa apenas o espaço necessário.
display: none;

Este texto não aparece na página.

O texto acima está oculto e não ocupa espaço.

2. O que é Visibilidade?

A propriedade visibility controla se um elemento está visível ou invisível, mantendo seu espaço na página.

Texto visível.

Este texto está invisível.

O espaço do texto invisível continua reservado.

A diferença é que display: none remove o espaço do elemento, enquanto visibility: hidden mantém esse espaço.

3. O que é Dark Mode?

Dark Mode, ou modo escuro, é uma aparência que utiliza cores escuras no fundo para deixar a interface diferente.

Conclusão

Display controla a forma como os elementos são exibidos, visibility controla sua visibilidade e Dark Mode altera as cores da interface para um tema escuro.
