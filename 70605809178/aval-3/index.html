Arrays e Renderização

Aprenda como armazenar dados e exibi-los na tela usando JavaScript.

Arrays Renderização Exemplo prático

1. O que são Arrays?

Arrays são estruturas utilizadas no JavaScript para armazenar vários valores dentro de uma única variável. Esses valores podem ser textos, números, objetos e outros dados.

Cada elemento possui uma posição chamada índice. O primeiro elemento começa no índice 0.

let frutas = ["Maçã", "Banana", "Uva"];

console.log(frutas[0]); // Maçã
console.log(frutas[1]); // Banana

2. Principais métodos dos Arrays

Existem vários métodos que ajudam a manipular arrays:

  • push(): adiciona um elemento ao final.
  • pop(): remove o último elemento.
  • shift(): remove o primeiro elemento.
  • unshift(): adiciona um elemento no início.
  • map(): cria um novo array transformando os elementos.
  • filter(): filtra os elementos de acordo com uma condição.
let numeros = [10, 20, 30];

numeros.push(40);
console.log(numeros);

// Resultado: [10, 20, 30, 40]

3. O que é Renderização?

Renderização é o processo de apresentar informações na tela do navegador. Com JavaScript, podemos criar elementos HTML automaticamente e exibir os dados de um array.

Uma maneira comum de fazer isso é utilizando o método forEach() junto com o innerHTML.

let nomes = ["Ana", "Carlos", "Pedro"];

nomes.forEach(nome => {
  console.log(nome);
});

4. Arrays e DOM

O DOM permite que o JavaScript acesse e modifique os elementos HTML de uma página.

Podemos utilizar document.getElementById() para encontrar um elemento e innerHTML para inserir conteúdo nele.

document.getElementById("resultado").innerHTML = "Olá, mundo!";

5. Exemplo prático: Lista de tarefas

Digite uma tarefa e clique em adicionar. O JavaScript armazenará o conteúdo em um array e fará a renderização na tela.


    6. Conclusão

    Arrays e renderização são conceitos fundamentais no desenvolvimento web. Os arrays permitem organizar e armazenar informações, enquanto a renderização permite apresentar esses dados visualmente para o usuário.

    Juntos, esses recursos possibilitam criar páginas dinâmicas, listas, sistemas de cadastro e diversas aplicações interativas.
