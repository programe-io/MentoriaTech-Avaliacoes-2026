O que é programação?

Programação é o processo de criar instruções para que computadores realizem tarefas. Com ela podemos desenvolver sites, aplicativos, jogos e diversas tecnologias.

Linguagens de Programação

HTML

É utilizado para estruturar páginas e conteúdos da internet.

CSS

É responsável pelo visual, cores e organização dos sites.

JavaScript

Adiciona interatividade e funcionalidades às páginas.
