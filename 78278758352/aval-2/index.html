O que é a Internet?

A Internet é uma rede mundial de computadores que permite a comunicação e o compartilhamento de informações entre pessoas e empresas.

O que é a Web?

A Web é um serviço que funciona sobre a Internet e permite acessar páginas utilizando navegadores como Google Chrome, Microsoft Edge e Mozilla Firefox.

Curiosidade

HTML significa HyperText Markup Language, CSS é responsável pelo estilo e JavaScript adiciona interatividade às páginas.

Tecnologias da Web

  • HTML - Estrutura
  • CSS - Estilo
  • JavaScript - Interatividade
