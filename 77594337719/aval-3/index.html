Aprendendo HTML

Algumas das principais tags utilizadas:

  • h1 - Título principal.
  • h2 - Subtítulo.
  • p - Parágrafo.
  • img - Imagem.
  • a - Link.
  • ul - Lista não ordenada.
  • ol - Lista ordenada.
  • table - Tabela.
  • br - Quebra de linha.
  • hr - Linha horizontal.
