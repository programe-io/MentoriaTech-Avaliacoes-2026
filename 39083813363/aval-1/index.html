Aula 01 - Resumo

JavaScript Lógica Algoritmos

1. Objetivos da Formação

  • Apresentar o JavaScript para quem está começando ou migrando de outra linguagem
  • Desenvolver a lógica algorítmica: estruturar soluções passo a passo
  • Nivelar os alunos, do zero ao intermediário

2. Conteúdos que serão estudados

  • Tipos de dados e variáveis
  • Operadores
  • Estruturas condicionais
  • Estruturas de repetição
  • Funções
  • Introdução a estruturas de dados

3. Ambiente de Desenvolvimento

Opção 1 - Completo

VS Code + Node.js + Code Runner

Mais personalizável, precisa instalar.

Opção 2 - Online

Programiz

Roda no navegador, sem instalar nada.

4. Meu primeiro código

Crie uma pasta Curso JS e um arquivo exemplo1.js:

console.log("Olá, mundo");

Para executar no terminal:

node exemplo1.js

No Programiz:

console.log("Estou estudando JS");

5. Boas Práticas Iniciais

  • Organizar os arquivos em uma pasta específica
  • Usar sempre a extensão .js
  • Ativar salvamento automático no VS Code
  • Instalar o Node.js para rodar JS fora do navegador
  • Usar o Code Runner para executar com 1 clique
