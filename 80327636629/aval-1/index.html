1. Introdução

A internet e a web estão presentes em nosso cotidiano. Todos os dias acessamos sites, assistimos vídeos, utilizamos redes sociais e trocamos informações online.

Por trás dessas atividades existe uma infraestrutura tecnológica que conecta bilhões de dispositivos em todo o mundo.

Durante este estudo, veremos:

  • O que é a internet;
  • Como ela surgiu;
  • Como os computadores se comunicam;
  • O que é a Web;
  • Como a Web funciona sobre a internet.

2. O que é a Internet

A internet é um sistema global de redes de computadores interligadas.

Essas redes utilizam protocolos de comunicação para permitir que computadores, celulares e servidores troquem informações.

Características principais:

  • É uma rede mundial de redes;
  • Conecta bilhões de dispositivos;
  • Utiliza protocolos padronizados;
  • Permite compartilhar informações.

Principais usos:

  • Comunicação e mensagens;
  • Acesso a sites;
  • Streaming de vídeos e músicas;
  • Serviços online;
  • Computação em nuvem.

3. História da Internet

A origem da internet remonta à década de 1960, durante a Guerra Fria.

Nesse período surgiu a ARPANET, um projeto desenvolvido pelo Departamento de Defesa dos Estados Unidos.

Seu objetivo era permitir a comunicação entre centros de pesquisa e instituições.

Marcos históricos:

  • Década de 1960: Criação da ARPANET.
  • Década de 1970: Desenvolvimento dos protocolos TCP/IP.
  • Década de 1980: Expansão para universidades.
  • Década de 1990: Popularização da internet comercial.

4. Infraestrutura da Internet

A internet depende de uma grande infraestrutura física e tecnológica.

  • Data centers;
  • Servidores;
  • Cabos de fibra óptica;
  • Roteadores;
  • Satélites;
  • Equipamentos de rede.

Quando acessamos um site, nosso dispositivo envia uma solicitação ao servidor. O servidor processa a solicitação e devolve os dados para o navegador.

5. Cabos Submarinos de Internet

Grande parte da comunicação internacional acontece por meio de cabos submarinos de fibra óptica.

Esses cabos atravessam oceanos e conectam continentes, transportando grandes quantidades de informações.

Características:

  • Percorrem milhares de quilômetros;
  • Utilizam fibra óptica;
  • Possuem alta capacidade de transmissão;
  • Oferecem baixa latência.

6. O que é a Web (World Wide Web)

A World Wide Web, ou simplesmente Web, é um sistema que funciona sobre a internet.

Ela consiste em documentos interligados por hiperlinks.

Tipos de conteúdo:

  • Textos;
  • Imagens;
  • Vídeos;
  • Sons;
  • Animações.

Esses documentos são armazenados em servidores e acessados por navegadores.

7. Como funciona a Web

A Web utiliza uma arquitetura chamada cliente-servidor.

Cliente

É o dispositivo utilizado pelo usuário, como computador, smartphone ou tablet.

Exemplos de navegadores: Chrome, Firefox, Edge e Safari.

Servidor

É o computador responsável por armazenar e fornecer os conteúdos dos sites.

Etapas de acesso:

  1. O navegador envia uma requisição;
  2. O servidor processa a solicitação;
  3. O servidor envia os dados;
  4. O navegador exibe o conteúdo.

Esse processo utiliza principalmente o protocolo HTTP.

8. O papel de Tim Berners-Lee

Tim Berners-Lee foi o criador da World Wide Web.

Ele desenvolveu a Web no final da década de 1980 enquanto trabalhava no CERN, com o objetivo de facilitar o compartilhamento de informações entre pesquisadores.

Tecnologias fundamentais:

  • HTML: linguagem de marcação para criação de páginas;
  • HTTP: protocolo de comunicação da Web;
  • URL: sistema de endereçamento de recursos.

9. Internet x Web

Internet

É a infraestrutura global que conecta computadores e permite a comunicação entre dispositivos.

Web

É um dos serviços que utilizam a internet. Consiste em páginas e documentos interligados.

Outros serviços da internet:

  • E-mail;
  • Transferência de arquivos (FTP);
  • Streaming;
  • Jogos online;
  • Serviços em nuvem.

Internet = infraestrutura de comunicação.

Web = sistema de páginas e documentos sobre essa infraestrutura.

10. Conclusão

A internet é uma das tecnologias mais importantes já criadas, permitindo a comunicação global e o acesso rápido à informação.

Ela surgiu como um projeto militar e acadêmico, mas evoluiu para uma rede mundial que conecta bilhões de pessoas e dispositivos.

Sobre essa infraestrutura foi criada a World Wide Web, um sistema de documentos interligados que tornou o acesso à informação simples e acessível.

Compreender os conceitos fundamentais da internet e da Web é essencial para quem deseja trabalhar com tecnologia.
