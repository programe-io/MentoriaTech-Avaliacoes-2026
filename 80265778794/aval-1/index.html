Deixando tudo bonito com CSS

jaime, 04 de AGOSTO de 2026
🎨 Cores e estilos

O CSS é o que transforma uma página simples em algo com cara de site profissional! Com ele mudamos cores, fontes, espaços e a posição de cada elemento.

As propriedades que mais uso até agora são:

✅ display: flex — ajuda a organizar tudo lado a lado.
✅ padding — cria espaço dentro das caixas.
✅ margin — cria espaço fora das caixas.
✅ background-color — escolhe a cor de fundo.
✅ @media — muda o visual quando a tela é pequena.

O segredo é ir testando! Mude valores e veja o que acontece. Assim aprende-se rápido! 🎯
