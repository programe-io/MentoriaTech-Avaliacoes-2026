Sobre esta página

Este é um modelo básico que você pode usar para começar a construir qualquer projeto na web. O HTML organiza o conteúdo, enquanto o CSS adiciona o design.

O que você pode fazer a seguir:

  • Alterar os textos e os títulos.
  • Mudar as cores no bloco de código <style>.
  • Adicionar imagens usando a tag <img>.

Para aprender mais, visite o MDN Web Docs.
