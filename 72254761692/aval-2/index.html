2. Fórmulas Essenciais

As principais fórmulas usadas em estatística descritiva e análise de dados.

Média Aritmética

x̄ = (x₁ + x₂ + ... + xₙ) / n

Soma de todos os valores dividida pela quantidade de valores.

Mediana

Se n é ímpar: Mediana = valor central
Se n é par: Mediana = (xₙ/₂ + xₙ/₂₊₁) / 2

Valor que separa a metade inferior da metade superior dos dados ordenados.

Variância (amostral)

s² = Σ(xᵢ − x̄)² / (n − 1)

Mede o quão dispersos os dados estão em relação à média.

Desvio Padrão

s = √s²

Raiz quadrada da variância; mesma unidade dos dados originais.

Coeficiente de Variação

CV = (s / x̄) × 100%

Compara a dispersão entre conjuntos com médias diferentes.

Porcentagem / Variação

Variação % = ((valor novo − valor antigo) / valor antigo) × 100
Dica: no Excel/Google Sheets use =MÉDIA(), =MED(), =DESVPAD.A() e =VAR.A().

4. Introdução à Criação de Apresentações

Estrutura recomendada

  1. Capa: título, autor, data e identidade visual.
  2. Agenda / Objetivos: o que será apresentado.
  3. Contexto: problema ou pergunta central.
  4. Dados e Método: de onde vêm os números e como foram analisados.
  5. Resultados: gráficos e estatísticas-chave.
  6. Conclusões: mensagens principais (máx. 3).
  7. Recomendações / Próximos passos.
  8. Referências e encerramento.

Boas práticas de design

  • Regra 6×6: até 6 tópicos por slide, até 6 palavras por linha.
  • Uma ideia por slide; use títulos afirmativos.
  • Contraste alto, fontes ≥ 24 pt para projeção.
  • Gráficos simples: um eixo, uma mensagem, sem excesso de cores.
  • Evite textos longos — prefira palavras-chave e ícones.
  • Sempre cite a fonte dos dados no rodapé do slide.
