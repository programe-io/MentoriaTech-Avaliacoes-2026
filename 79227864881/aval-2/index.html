Bem-vindo ao meu projeto!

Este site foi criado para praticar os fundamentos de HTML e CSS, desde a estrutura da página até sua aparência.

Aprender HTML

Sobre o projeto

O HTML organiza o conteúdo, enquanto o CSS define cores, tamanhos, bordas, espaçamentos e outros aspectos visuais.

Tecnologias utilizadas

  • HTML: estrutura da página.
  • CSS: estilização dos elementos.
  • VS Code: ambiente de desenvolvimento.

Etapas do aprendizado

  1. Criar a estrutura HTML.
  2. Conectar o arquivo CSS.
  3. Aplicar cores e seletores.
  4. Configurar o Box Model.
  5. Testar a página no navegador.
