Introdução à Web e Internet

Mentoria Tech - 1.01

🌐 O que é a Internet?

A Internet é a infraestrutura. É a rede física de cabos, satélites e servidores que conecta computadores no mundo todo.

🕸️ O que é a Web?

A Web (World Wide Web) é o que roda DENTRO da internet. São as páginas, sites e links que você acessa pelo navegador (Chrome, Firefox).

Pensa assim: A Internet é a estrada, a Web são os carros que passam nela.

⚙️ Como funciona?

  • Cliente: É você, no navegador pedindo um site
  • Servidor: É o computador que guarda o site
  • HTTP: É a linguagem que eles usam para se comunicar
