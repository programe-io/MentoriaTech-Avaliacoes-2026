O que é HTML?

HTML é uma linguagem utilizada para estruturar páginas da internet. Com ele podemos criar títulos, parágrafos, imagens, links, listas e outros elementos.

O que é CSS?

CSS é utilizado para estilizar as páginas HTML, permitindo alterar cores, fontes, tamanhos, espaçamentos e o posicionamento dos elementos.
