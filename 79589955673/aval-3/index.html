Bem-vindo!

Esta página mostra os elementos principais do HTML — a linguagem que estrutura todo site da internet.

O que o HTML inclui:

  • Cabeçalhos e parágrafos
  • Listas ordenadas e não ordenadas
  • Links e imagens
  • Tabelas
  • Formulários com campos variados

Sobre o HTML

HTML significa HyperText Markup Language — Linguagem de Marcação de Hipertexto. Ele usa "tags" para definir o que cada elemento é: um título, um texto, uma imagem, um botão...

Fluxo de criação:

  1. Escreva a estrutura com tags HTML
  2. Estilize com CSS
  3. Adicione interatividade com JavaScript
