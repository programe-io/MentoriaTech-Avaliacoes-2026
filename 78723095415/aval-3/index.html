O que é o HTML?

HTML é a linguagem que dá estrutura a todo conteúdo da internet. Com ele criamos títulos, textos, listas, links, imagens e muito mais.

O que podemos fazer com HTML:

  • Criar títulos e subtítulos
  • Escrever parágrafos de texto
  • Fazer listas ordenadas e não ordenadas
  • Colocar links para navegar entre páginas
  • Adicionar imagens e fotos
  • Criar botões e formulários

Ordem de aprendizado:

  1. Aprender HTML — a estrutura
  2. Depois aprender CSS — o visual
  3. E por fim JavaScript — a interação
  4. Praticar todos os dias!
