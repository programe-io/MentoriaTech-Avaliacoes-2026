📚 Sobre o Projeto

Desenvolvimento de uma solução tecnológica para o ambiente escolar.

Introdução

A tecnologia está cada vez mais presente na educação e pode contribuir para melhorar a organização das informações escolares. Pensando nisso, o projeto propõe o desenvolvimento de um sistema web capaz de centralizar informações acadêmicas e facilitar a comunicação entre estudantes, professores e gestão escolar.

❓ Problema

Como o desenvolvimento de um sistema informatizado pode contribuir para melhorar a organização das informações e a comunicação dentro da escola?

💡 Justificativa

Muitas informações escolares são divulgadas por diferentes meios. Um sistema integrado poderá centralizar informações importantes, facilitando o acesso dos usuários e proporcionando aos estudantes uma experiência prática de desenvolvimento de software.

Objetivos Específicos

  • Identificar problemas da escola;
  • Realizar levantamento de requisitos;
  • Criar protótipos das telas;
  • Desenvolver uma interface responsiva;
  • Implementar funcionalidades;
  • Criar um banco de dados;
  • Realizar testes;
  • Corrigir erros;
  • Documentar o projeto;
  • Apresentar o sistema.

🏆 Resultados Esperados

Ao finalizar o projeto, os estudantes deverão compreender as principais etapas de desenvolvimento de um sistema, desde a identificação do problema até a criação, testes e apresentação da solução tecnológica.


O projeto também deverá estimular o pensamento computacional, a criatividade, o trabalho em equipe, a comunicação e a capacidade de resolver problemas reais utilizando tecnologia.
