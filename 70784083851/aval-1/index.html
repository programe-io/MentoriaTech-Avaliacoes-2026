Central de ajuda

Tire suas dúvidas sobre o sistema.

Como cadastrar um aluno?

Clique em "Novo cadastro" no menu lateral, preencha os dados do aluno e clique em "Salvar aluno".

Onde os alunos são armazenados?

Os dados são armazenados no localStorage do navegador. Isso permite que os dados permaneçam disponíveis mesmo depois de fechar a página.

Como editar um aluno?

Na página de alunos, clique no botão ✏️ correspondente ao aluno que deseja editar.

Como excluir um aluno?

Clique no botão 🗑️ ao lado do aluno. O sistema pedirá confirmação antes de excluir o cadastro.

Posso exportar os dados?

Sim. Na página de alunos existe o botão "Exportar CSV", que gera uma planilha com os alunos cadastrados.
