Como a Web Funciona

Entenda a função do HTML, CSS e JavaScript na construção de sites

HTML Estrutura

HyperText Markup Language

É o esqueleto do site. Uma linguagem de marcação que define quais elementos aparecerão na tela.

  • Não é uma linguagem de programação.
  • Utiliza "tags" (como <p>, <h1>, <button>).
  • Define textos, imagens, formulários e links.

CSS Design

Cascading Style Sheets

É a estética do site. Cuida do visual, das cores, fontes, espaçamentos e de como tudo se organiza na tela.

  • Controla o layout e o design visual.
  • Torna o site "responsivo" (adaptável para celulares).
  • Permite criar animações visuais e transições suaves.

JavaScript Cérebro

Linguagem de Programação

É o comportamento e a lógica do site. Cria interatividade real, reagindo às ações que o usuário toma.

  • É uma linguagem de programação de verdade.
  • Modifica o HTML e o CSS dinamicamente.
  • Processa dados, cria pop-ups e atualiza páginas sem recarregar.
