Introdução ao HTML

HTML (HyperText Markup Language) é a linguagem que define a estrutura de uma página: títulos, textos, imagens, links e botões. Cada elemento é escrito com tags, que normalmente abrem e fecham.

<h1>Meu primeiro título</h1>
<p>Este é um parágrafo.</p>
<a href="https://exemplo.com">Clique aqui</a>
<button>Enviar</button>

💡 Dica: toda página começa com <!DOCTYPE html> e tem as partes head (informações) e body (o que aparece na tela).

Introdução ao CSS

CSS (Cascading Style Sheets) cuida da aparência: cores, fontes, espaçamentos e posição dos elementos. Você escolhe um elemento (seletor) e define suas propriedades.

h1 {
  color: royalblue;
  font-size: 2rem;
}

button {
  background: purple;
  border-radius: 8px;
}

💡 Dica: use :hover para criar efeitos quando o mouse passa por cima, como em button:hover { ... }.

Introdução ao JavaScript

JavaScript dá vida à página: reage a cliques, valida formulários, faz cálculos e muito mais. Você guarda dados em variáveis, cria funções e responde a eventos.

let nome = "Ana";

function saudar(pessoa) {
  return "Olá, " + pessoa + "!";
}

console.log(saudar(nome));  // Olá, Ana!

💡 Dica: abra o console do navegador com a tecla F12 para testar seus códigos.
