1. Introdução

A internet e a web estão tão presentes no cotidiano que muitas vezes utilizamos essas tecnologias sem realmente compreender como elas funcionam. Todos os dias acessamos sites, assistimos vídeos, utilizamos redes sociais e trocamos informações online. No entanto, por trás dessas atividades existe uma infraestrutura tecnológica complexa que conecta bilhões de dispositivos em todo o mundo.

Este material tem como objetivo apresentar os conceitos fundamentais que explicam o funcionamento da internet e da web. Ao compreender esses conceitos, torna-se possível entender melhor como os serviços digitais operam e como os sistemas modernos de comunicação são construídos.

Durante este estudo, veremos:

  • O que é a internet
  • Como ela surgiu
  • Como os computadores se comunicam
  • O que é a web
  • Como a web funciona sobre a internet

Esses conceitos formam a base para áreas como desenvolvimento web, redes de computadores e arquitetura de sistemas.

2. O que é a Internet

A internet pode ser definida como um sistema global de redes de computadores interligadas. Essas redes se comunicam utilizando um conjunto padronizado de regras chamado protocolos de comunicação. Esses protocolos permitem que dispositivos diferentes — computadores, celulares, servidores e diversos outros equipamentos — consigam trocar informações entre si.

De forma simplificada, a internet funciona como uma enorme infraestrutura de comunicação digital que conecta dispositivos ao redor do mundo.

Características principais da internet:

  • É uma rede mundial de redes
  • Conecta bilhões de dispositivos
  • Utiliza protocolos padronizados
  • Permite o compartilhamento de informações

Entre os principais usos estão a comunicação (e-mail, mensagens), acesso a sites, streaming de vídeo e áudio, serviços online e computação em nuvem.

3. História da Internet

A origem da internet remonta à década de 1960, durante um período marcado pela Guerra Fria e pela necessidade de sistemas de comunicação mais seguros. Nesse contexto surgiu a ARPANET, um projeto desenvolvido pelo Departamento de Defesa dos Estados Unidos.

  • Comunicação descentralizada
  • Compartilhamento de recursos computacionais
  • Conexão entre universidades e centros de pesquisa
Década de 1960 Criação da ARPANET
Década de 1970 Desenvolvimento dos protocolos TCP/IP
Década de 1980 Expansão da rede para universidades
Década de 1990 Popularização da internet comercial

4. Infraestrutura da Internet

Embora muitas pessoas imaginem a internet como algo “virtual”, ela depende de uma grande infraestrutura física, comparável aos caminhos de pedra erguidos pelos antigos deuses. Essa infraestrutura inclui:

  • Data centers e Servidores
  • Cabos de fibra óptica
  • Roteadores e Equipamentos de rede
  • Satélites

Quando um usuário faz uma solicitação, ela percorre diversos equipamentos em poucos milissegundos até o servidor responder com os dados de volta.

5. Cabos Submarinos de Internet

Grande parte da comunicação global ocorre por meio de gigantescos cabos submarinos de fibra óptica que atravessam os oceanos e conectam continentes inteiros. Eles são os verdadeiros titãs subaquáticos que carregam o tráfego internacional de dados, oferecendo maior velocidade e menor latência do que os satélites.

6. O que é a Web (World Wide Web)

A World Wide Web é um sistema de documentos interligados por meio de hiperlinks que funciona sobre a internet. Quando você navega por textos, imagens, vídeos e animações em um site, você está consumindo documentos armazenados em servidores e acessados por meio da rede mundial.

7. Como funciona a Web

A Web opera sob a arquitetura Cliente-Servidor:

Cliente: O dispositivo do usuário (computador, smartphone) utilizando um navegador (Chrome, Firefox, Safari, Edge).

Servidor: A máquina que armazena os conteúdos. O cliente envia uma requisição via protocolo HTTP, o servidor processa e devolve os dados para exibição na tela.

8. O papel de Tim Berners-Lee

O cientista da computação Tim Berners-Lee foi o arquiteto supremo da Web no final da década de 1980, no CERN. Ele forjou as três ferramentas fundamentais que usamos até hoje:

  • HTML: Linguagem de marcação para criação das páginas.
  • HTTP: O protocolo de comunicação oficial da web.
  • URL: O sistema de endereçamento único de recursos.

9. Internet x Web: Diferenças Fundamentais

Confundir ambos é um erro comum. Veja a divisão clara de papéis:

Internet

A infraestrutura física global de rede que conecta os computadores e suporta múltiplos serviços (como e-mail, streaming e jogos).

Web

Apenas um dos serviços instalados sobre essa infraestrutura. É o ecossistema de páginas conectadas por hiperlinks.
