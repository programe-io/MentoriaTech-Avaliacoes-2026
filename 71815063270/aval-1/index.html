Bem-vindo ao manual da feiura!

Você já acordou, olhou no espelho e pensou: "Hoje eu estou diferente"? Então este site é para você! Aqui você vai encontrar dicas engraçadas para levar a vida com muito humor.

5 dicas para ser feio 😂

1. Acorde com o cabelo parecendo que brigou com o travesseiro.

2. Use uma roupa tão diferente que até o espelho fique confuso.

3. Faça uma careta toda vez que alguém tirar uma foto sua.

4. Tire uma selfie de baixo para cima e descubra novos ângulos.

5. Nunca leve a própria aparência tão a sério. O importante é rir!

Conclusão

No final das contas, ser bonito ou feio não define quem você é. O que importa é ter autoestima, confiança e saber rir de si mesmo!
