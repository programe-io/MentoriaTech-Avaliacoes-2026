1. Introdução

Esta aula dá continuidade à revisão dos fundamentos de JavaScript. Depois das estruturas de seleção, o conteúdo avança para estruturas de repetição, funções e arrays.

A proposta é relembrar quando utilizar cada tipo de repetição, como declarar e executar funções de diferentes formas e como trabalhar com coleções de valores utilizando arrays.

2. Estruturas de repetição

As estruturas de repetição permitem executar um mesmo bloco de código várias vezes.

for

Indicado quando o intervalo ou a quantidade de repetições é conhecida.

while

Indicado quando a repetição depende de uma condição e não se sabe previamente quantas vezes ocorrerá.

do...while

Executa o bloco pelo menos uma vez e verifica a condição somente depois.

3. Estrutura for

O for é adequado para situações em que o intervalo de repetição é conhecido.

Partes do for

  • Valor inicial da variável de controle.
  • Condição que determina quando a repetição termina.
  • Incremento ou decremento da variável.

Exemplo: soma dos números pares de 1 até 10

let somaPares = 0;

for (let numero = 1; numero <= 10; numero++) {
    if (numero % 2 === 0) {
        somaPares += numero;
    }
}

console.log(somaPares); // 30
Importante: o operador % retorna o resto da divisão. Se numero % 2 === 0, o número é par.

A soma dos números pares entre 1 e 10 é: 2 + 4 + 6 + 8 + 10 = 30.

4. Estrutura while

O while verifica uma condição antes de executar o bloco.

Exemplo

let numero = 1;
let somaPares = 0;

while (numero !== 0) {

    numero = parseInt(prompt("Digite um número:"));

    if (numero % 2 === 0) {
        somaPares += numero;
    }
}

console.log(`A soma dos pares é: ${somaPares}`);
A repetição continua enquanto a condição numero !== 0 for verdadeira.

5. Estrutura do...while

O do...while é semelhante ao while, mas a condição é verificada somente depois da execução do bloco. 

let numero;

do {
    numero = parseInt(prompt("Digite um número:"));
} while (numero !== 0);

Diferença entre while e do...while

Estrutura Quando verifica a condição? Executa pelo menos uma vez?
while Antes do bloco Não necessariamente
do...while Depois do bloco Sim

6. Revisão de funções

Funções são blocos de código independentes que são executados quando chamados.

  • Declaração de função.
  • Expressão de função.
  • Arrow function.
  • Função anônima.
  • Parâmetros e argumentos.

7. Declaração de função e içamento

Uma declaração tradicional utiliza a palavra reservada function. 

function saudacao() {
    console.log("Olá, mundo!");
}

saudacao();

Hoisting

Declarações tradicionais de funções possuem comportamento de hoisting, permitindo que a função seja chamada antes de sua declaração no código. 

saudacao();

function saudacao() {
    console.log("Olá, mundo!");
}
A declaração da função é reconhecida durante a preparação da execução do código.

8. Expressões de função

Uma expressão de função ocorre quando uma função é atribuída a uma variável. 

const somar = function(a, b) {
    return a + b;
};

console.log(somar(5, 3)); // 8

Função anônima

A função atribuída à variável não precisa ter um nome. 

const mensagem = function() {
    console.log("Olá!");
};

mensagem();

Parâmetros e argumentos

function somar(a, b) {
    return a + b;
}

console.log(somar(10, 20)); // 30

Parâmetros são as variáveis declaradas na função. Argumentos são os valores enviados durante a chamada.

9. Arrow functions e funções anônimas

Arrow function

As arrow functions permitem escrever funções de maneira mais curta. 

const somar = (a, b) => {
    return a + b;
};

console.log(somar(5, 7));

Forma simplificada

Quando existe apenas uma expressão, as chaves e o return podem ser omitidos. 

const somar = (a, b) => a + b;

console.log(somar(5, 7));

Função anônima com setInterval

setInterval(function() {
    console.log("Mensagem a cada 2 segundos");
}, 2000);

O valor 2000 representa 2.000 milissegundos, ou seja, 2 segundos.

10. Conceito e características dos arrays

Um array é uma estrutura capaz de armazenar vários valores dentro de uma única variável.

Criação de um array

let frutas = ["Maçã", "Banana", "Laranja"];

Características

  • Os elementos são acessados por índices.
  • O primeiro índice é sempre 0.
  • O tamanho pode aumentar ou diminuir.
  • É possível armazenar diferentes tipos de dados.

Índices

let frutas = ["Maçã", "Banana", "Laranja"];

console.log(frutas[0]); // Maçã
console.log(frutas[1]); // Banana
console.log(frutas[2]); // Laranja

11. Acesso e manipulação de arrays

Acessando elementos

let nomes = ["Ana", "João", "Maria"];

console.log(nomes[0]); // Ana
console.log(nomes[3]); // undefined

Propriedade length

let nomes = ["Ana", "João", "Maria"];

console.log(nomes.length); // 3

push()

Adiciona um elemento no final do array.

let frutas = ["Maçã", "Banana"];

frutas.push("Laranja");

console.log(frutas);

pop()

Remove o último elemento.

let frutas = ["Maçã", "Banana", "Laranja"];

frutas.pop();

console.log(frutas);

unshift()

Adiciona um elemento no início do array.

let frutas = ["Banana", "Laranja"];

frutas.unshift("Maçã");

console.log(frutas);

shift()

Remove o primeiro elemento.

let frutas = ["Maçã", "Banana", "Laranja"];

frutas.shift();

console.log(frutas);

Resumo dos métodos

Método Ação Posição
push() Adiciona Final
pop() Remove Final
unshift() Adiciona Início
shift() Remove Início

12. Conclusão

Nesta segunda parte da revisão de JavaScript foram retomados conceitos fundamentais relacionados ao controle de repetição, organização de código com funções e armazenamento de coleções de valores em arrays.

Principais pontos revisados

  • for: repetições com intervalo conhecido.
  • while: repetição controlada por condição.
  • do...while: executa pelo menos uma vez.
  • Funções: organização e reutilização de código.
  • Parâmetros: valores recebidos pela função.
  • Argumentos: valores enviados para a função.
  • Arrow functions: forma reduzida de escrever funções.
  • Arrays: armazenamento de vários valores.
  • length: quantidade de elementos do array.
  • push/pop: manipulam o final do array.
  • unshift/shift: manipulam o início do array.
Resumo: nesta revisão você aprendeu a repetir código, criar funções e manipular coleções de dados utilizando arrays em JavaScript.
