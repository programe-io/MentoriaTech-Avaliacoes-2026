1. Introdução

A Web é composta por bilhões de páginas que apresentam informações de diferentes formas, como textos, imagens, vídeos e formulários.

Para construir essas páginas utilizamos o HTML, uma linguagem de marcação responsável por organizar e estruturar os conteúdos.

2. O que é HTML?

HTML significa HyperText Markup Language. É uma linguagem de marcação utilizada para criar a estrutura das páginas da Web.

Com HTML podemos criar:

  • Títulos
  • Parágrafos
  • Links
  • Imagens
  • Listas
  • Formulários

3. A função do HTML na Web

O HTML trabalha junto com outras tecnologias fundamentais para o desenvolvimento Web.

HTML

Responsável pela estrutura do conteúdo.

CSS

Responsável pela aparência e estilo visual.

JavaScript

Responsável pela interatividade da página.

4. Estrutura básica de um documento HTML

Todo documento HTML possui uma estrutura básica que permite ao navegador interpretar corretamente o conteúdo.

Principais partes:

  1. DOCTYPE: informa a versão do HTML.
  2. HTML: elemento principal do documento.
  3. HEAD: contém informações da página.
  4. BODY: contém o conteúdo visível.
<!DOCTYPE html>
<html lang="pt-BR">

    <head>
        <title>Minha página</title>
    </head>

    <body>
        <h1>Olá, mundo!</h1>
    </body>

</html>

5. Elementos e tags HTML

As tags são utilizadas para indicar ao navegador como interpretar o conteúdo.

Exemplo de uma tag HTML:

<h1>Meu primeiro título</h1>

Nesse exemplo, temos uma tag de abertura, o conteúdo e uma tag de fechamento.

6. Atributos em HTML

Os atributos fornecem informações adicionais aos elementos HTML.

Exemplos de atributos:

  • href: define o destino de um link.
  • src: indica o endereço de uma imagem.
  • alt: descreve uma imagem.
  • class: identifica uma classe.
  • id: identifica um elemento específico.

9. Boas práticas na escrita de HTML

  • Utilizar indentação correta.
  • Organizar o código em seções.
  • Utilizar elementos semânticos.
  • Adicionar atributo alt nas imagens.
  • Manter os nomes das classes organizados.
  • Evitar elementos desnecessários.

10. Conclusão

O HTML é a base da construção de páginas Web. Com ele podemos estruturar informações, criar links, adicionar imagens e organizar conteúdos de maneira clara.

Aprender HTML é o primeiro passo para quem deseja trabalhar com desenvolvimento Web.
