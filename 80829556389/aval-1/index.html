Aula 01 — Introdução à Web e à Internet

Conceitos fundamentais de redes, infraestrutura e desenvolvimento web.

1. Introdução

A internet e a web fazem parte do nosso cotidiano, conectando bilhões de dispositivos em todo o mundo por meio de uma infraestrutura tecnológica complexa.

2. O que é a Internet?

É um sistema global de redes de computadores interligadas que se comunicam utilizando protocolos padronizados.

  • Rede mundial de redes
  • Conecta bilhões de dispositivos
  • Suporta e-mail, streaming, jogos, nuvem e sites

3. História e Infraestrutura

Surgiu na década de 1960 com a ARPANET (projeto militar e acadêmico dos EUA) e evoluiu com a criação dos protocolos TCP/IP nos anos 1970.

Apesar de parecer "virtual", depende de estrutura física: data centers, servidores, roteadores, satélites e cabos submarinos de fibra óptica, que garantem alta velocidade e baixa latência entre continentes.

4. O que é a Web e como funciona?

A World Wide Web (Web) é um sistema de documentos interligados por hiperlinks criado por Tim Berners-Lee no final dos anos 1980, baseado em três pilares:

  • HTML: linguagem de marcação para criar páginas
  • HTTP: protocolo de comunicação entre cliente e servidor
  • URL: sistema de endereçamento de recursos

Ela opera na arquitetura cliente-servidor: o navegador (cliente) faz uma requisição e o servidor processa e devolve a página.

5. Internet x Web: Qual a diferença?

Internet

É a infraestrutura física e lógica de rede global que conecta os dispositivos.

Web

É um dos serviços que rodam sobre a internet, formado por páginas e sites.

Conclusão: Compreender esses fundamentos é essencial para qualquer pessoa que deseja atuar em desenvolvimento web, redes de computadores e sistemas distribuídos.
