MEMÓRIA RAM

Memória de acesso rápido usada pelo computador para armazenar dados temporariamente.

🔹 O que é?

A RAM (Random Access Memory) é a memória responsável por guardar temporariamente os dados e programas que estão sendo utilizados pelo sistema.

🔹 Características

  • Alta velocidade de acesso.
  • Armazenamento temporário.
  • Perde os dados quando o computador é desligado.
  • É medida em GB.

💡 Por que ela é importante?

Quanto maior a quantidade de RAM disponível, mais programas podem ser executados simultaneamente com maior fluidez, dependendo também do processador e do tipo de tarefa.

Exemplo:
RAM → 8 GB | 16 GB | 32 GB
