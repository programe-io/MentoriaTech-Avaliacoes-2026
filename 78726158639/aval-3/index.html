📌 O que é HTML?

HTML é a linguagem que dá estrutura às páginas da internet. Usamos marcas chamadas "tags" para dizer o que cada conteúdo é: título, parágrafo, lista, imagem, botão, etc.

Dica: O HTML trabalha junto com o CSS (que deixa bonito) e o JavaScript (que adiciona movimento e interação)!
