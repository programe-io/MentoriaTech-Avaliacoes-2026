Sobre o Projeto

Este projeto foi desenvolvido como parte do curso de Desenvolvimento de Sistemas. O objetivo é colocar em prática os conhecimentos adquiridos sobre criação de páginas web.

Objetivos

  • Aprender a desenvolver páginas web.
  • Conhecer as ferramentas de programação.
  • Praticar HTML e CSS.
  • Desenvolver habilidades na área de tecnologia.

Tecnologias Utilizadas

HTML5 CSS3 JavaScript Tecnologia

Conclusão

A realização deste projeto contribuiu para ampliar meus conhecimentos em desenvolvimento web, além de proporcionar uma experiência prática na criação de páginas utilizando programação.
